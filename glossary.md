## Week 1 — Human Visual System
*(full explanations in [`week1-study-notes.md`](./week1-study-notes.md); this is the lookup-speed version)*

- **[Aperture](https://en.wikipedia.org/wiki/Aperture)** — camera terminology for the opening that controls how much light gets let in (a wider opening = more light); the pupil is the eye's own aperture. Deepened in Week 2.
- **[Image sensor](https://en.wikipedia.org/wiki/Image_sensor)** — the electronic chip behind a camera's lens that converts incoming light into a digital image, sitting where photographic film used to go; the retina plays the same biological role. Deepened in Week 2.
- **[Accommodation](https://en.wikipedia.org/wiki/Accommodation_(vertebrate_eye))** — the eye changing focus by reshaping its lens via the ciliary muscle.
- **[Fovea](https://en.wikipedia.org/wiki/Fovea_centralis)** — the small, cone-dense pit in the retina responsible for sharp central vision.
- **[Rods](https://en.wikipedia.org/wiki/Rod_cell) / [cones](https://en.wikipedia.org/wiki/Cone_cell)** — the retina's two photoreceptor types: rods for low-light/no-color vision, cones for color and fine detail.
- **[Metamerism](https://en.wikipedia.org/wiki/Metamerism_(color))** — two physically different light spectra producing identical cone responses, so they look like the same color.
- **[Bayer color filter array](https://en.wikipedia.org/wiki/Bayer_filter) / RGGB mosaic** — the physical grid of tiny red/green/green/blue filters glued onto a sensor, one per pixel, so each pixel measures only one color; the rest gets computationally filled in later ([demosaicking](https://en.wikipedia.org/wiki/Demosaicing), Week 3).
- **Visual angle / [arcminute](https://en.wikipedia.org/wiki/Minute_and_second_of_arc)** — the angular size an object subtends at the eye (1° = 60 arcmin); acuity and spatial frequency are both defined in these units, not raw distance.
- **[dpi (dots per inch)](https://en.wikipedia.org/wiki/Dots_per_inch)** — pixel *size* flipped into pixel *density*: if a pixel is p inches wide, dpi = 1/p. Historically a printing term ([ppi](https://en.wikipedia.org/wiki/Pixel_density) is the more precise word for screens), but used interchangeably with pixel density here (§9).
- **[Stereoscopic](https://en.wikipedia.org/wiki/Stereoscopy)** — literally "two-eyed viewing" (*stereo* + *scopic*); describes any device or display that feeds each eye a slightly different image (mimicking binocular disparity) so the brain perceives depth from an otherwise flat picture.
- **[Vergence-accommodation conflict (VAC)](https://en.wikipedia.org/wiki/Vergence-accommodation_conflict)** — the mismatch, in stereo displays, between where the eyes converge (simulated depth) and where they must focus (actual screen distance).
- **[Stop](https://en.wikipedia.org/wiki/Exposure_value)** — a factor of 2 in light; stops = log₂(ratio), so +2 = 4× the light and −4 = 1/16. Camera exposure compensation ("+2 EV") is written in stops, usually in third-stop steps of 2^(1/3) ≈ 1.26× (§14).
- **[Dynamic range](https://en.wikipedia.org/wiki/Dynamic_range)** — the ratio between the brightest and darkest signal a system (eye, sensor, or display) can represent, in f-stops or orders of magnitude (§15).
- **[Spatial frequency](https://en.wikipedia.org/wiki/Spatial_frequency)** — how rapidly *brightness* varies across an image, in cycles per unit distance (or cycles per degree, perceptually); not to be confused with the frequency of light itself (color, §6) or temporal frequency (flicker/frame rate, §16.1). Full buildup, including why the same pattern's cycles-per-degree changes with viewing distance, in §16.
- **Image frequency** — how rapidly brightness varies across a digital image's *pixel grid* (cycles per pixel), a fixed property of the file alone, independent of print size, display, or viewing distance. Converts into physical spatial frequency via dpi, and from there into cycles-per-degree via viewing distance — the full chain, worked numerically, is in §16.4.
- **[Weber contrast](https://en.wikipedia.org/wiki/Contrast_(vision)#Weber_contrast) / [Michelson contrast](https://en.wikipedia.org/wiki/Contrast_(vision)#Michelson_contrast)** — two different formulas for "contrast": Weber for one feature against a uniform background, Michelson for a repeating pattern.
- **[Contrast Sensitivity Function (CSF)](https://en.wikipedia.org/wiki/Contrast_(vision)#Contrast_sensitivity)** — the curve describing how sensitive the eye is to a given spatial frequency; band-pass, peaking around 4–6 cycles per degree.
- **[Fourier transform](https://en.wikipedia.org/wiki/Fourier_transform) (1D → 2D)** — the operation that rewrites a signal (a 1D signal like sound, or a 2D signal like an image) as a sum of sine waves of different frequency, amplitude, and phase; for images, the "wave" is a 2D sinusoidal grating with a horizontal frequency *u* and vertical frequency *v*. Introduced early, in §19, because HW1's hybrid-images task depends on it; formalized fully in Week 5.
- **Spatial domain / frequency domain** — two equally complete descriptions of the same image: spatial domain indexes by pixel location (ordinary "what color is here"); frequency domain indexes by `(u,v)` spatial-frequency pair (how much of that stripe pattern is present). The Fourier transform converts between them; nothing is lost (§19).
- **Spectrum (magnitude / phase)** — the Fourier transform's output, one complex number per `(u,v)` pair: magnitude = how strong that frequency is, phase = how it's shifted. Low `(u,v)` = coarse image content, high `(u,v)` = fine detail (§19.3).
- **DC component** — the `(u,v) = (0,0)` entry of a spectrum: zero spatial frequency, equal to the image's overall average brightness (§19.4).
- **[fftshift](https://en.wikipedia.org/wiki/Discrete_Fourier_transform) / ifftshift** — reorders a raw FFT output so the DC component moves from a corner to the center (`fftshift`), or undoes that reordering before an inverse transform (`ifftshift`) — needed because of how the discrete Fourier transform indexes negative frequencies (§19.4).
- **Convolution** — the operation of sliding a small list/grid of weights (the kernel) across a signal or image, multiplying and summing at each position: equivalently, stamping a copy of the kernel, scaled by each input value, at every input position and adding the stamps. Blurring is convolution; (x*h)[n] = Σ h[m]·x[n−m] (§20).
- **Kernel / filter / mask / template** — the small list or grid of weights `h` that convolution slides over the signal (a *tap* is one weight; the *support* is where it is nonzero). Optics call the blur kernel the PSF, signal processing calls it the impulse response. (A frequency-domain *mask* in §21 is a different object.) (§20)
- **Impulse / delta; impulse response** — the signal that is a single 1 among zeros; what a system outputs for it (a copy of its kernel) is its impulse response. For a camera, a single point of light and the blob it forms (§20; PSF in Week 4 §18.1).
- **Linear shift-invariant (LSI) system** — a system where scaling/adding inputs scales/adds outputs (linear) and shifting the input just shifts the output (shift-invariant). Every LSI system is a convolution with its impulse response, which is why one PSF can describe a whole camera's blur (§20).
- **Boundary handling (padding); full / same / valid** — what to assume beyond the signal's edge when a kernel overhangs it (zeros, repeated edge, mirror, or wrap-around, which the DFT assumes), and which output positions to keep (§20).
- **Cross-correlation / matched filter** — convolution's near-twin that slides the kernel without reversing it; correlating with a known pulse shape is the best linear way to detect that pulse in noise (used in LiDAR/ToF receivers) but does not sharpen (§20, §23).
- **[Convolution theorem](https://en.wikipedia.org/wiki/Convolution_theorem)** — multiplying two spectra in the frequency domain is mathematically identical to convolving (a sliding weighted average of) the corresponding signals in the spatial domain; the mechanism behind frequency-domain filtering (motivated in §20.7, applied in §21) and, later, the PSF and deconvolution (Weeks 5–6).
- **[Low-pass](https://en.wikipedia.org/wiki/Low-pass_filter) / [high-pass filter](https://en.wikipedia.org/wiki/High-pass_filter)** — operations that keep only coarse/smooth content, or only fine detail/edges, respectively.
- **Deconvolution (first look)** — the inverse problem of convolution: given the blurred result (and usually the kernel), recover the sharp original, in the simplest case by dividing the spectrum by the kernel's spectrum (the *inverse filter*). **Non-blind** = kernel known; **blind** = kernel also unknown. Hard because it is **ill-posed**: exact zeros in the kernel's spectrum destroy information and near-zeros amplify noise, so **regularization** (added assumptions, e.g. the Wiener filter in Week 5, priors in Week 6) is needed. Relevant to defocus/motion blur, coded imaging, and sharpening LiDAR range returns (§23).
- **Ill-posed problem** — one whose solution does not exist, is not unique, or changes wildly with tiny changes in the data; deconvolution is the standard example (§23).
- **System impulse response (LiDAR)** — the waveform a LiDAR records for one ideal reflector, set by the laser pulse's shape and the detector's timing response; the measured return is the true returns convolved with it (§23).
- **[Inner product](https://en.wikipedia.org/wiki/Inner_product_space) (dot product)** — multiply two vectors entry by entry and add up; a cone's response is the inner product of the sampled spectrum with that cone's sampled sensitivity curve, and each Fourier coefficient is the inner product of a signal with one sinusoid (§6, §19.1).
- **[Linear map / linear operator](https://en.wikipedia.org/wiki/Linear_map)** — a function that preserves sums and scaling, f(a·x + b·y) = a·f(x) + b·f(y), so it can be written as a matrix; the eye's spectrum-to-(L, M, S) map, the Bayer mosaic, and convolution are all examples (§6, §7, §20.7).
- **[Change of basis](https://en.wikipedia.org/wiki/Change_of_basis)** — rewriting the same vector's coordinates relative to a different set of basis vectors, via an invertible matrix; the DFT is a change of basis from spikes to sinusoids, and color spaces (XYZ, RGB) are changes of basis for (L, M, S) (§6, §19.1).
- **[Null space](https://en.wikipedia.org/wiki/Kernel_(linear_algebra))** — every input a matrix sends to zero, i.e. every change it cannot see; metamers differ by a null-space vector of the cone matrix, and the Bayer mosaic's null space is why demosaicking can't just invert it (§6, §7).
- **[Projection](https://en.wikipedia.org/wiki/Projection_(linear_algebra))** — a linear map P with P² = P that keeps one subspace and discards the rest; a 0/1 frequency mask is a projection onto the kept sinusoids, and I − P onto the others (§21, §22.2).
- **[Circulant](https://en.wikipedia.org/wiki/Circulant_matrix) / [Toeplitz matrix](https://en.wikipedia.org/wiki/Toeplitz_matrix)** — a matrix whose every row is the row above shifted by one (with wrap-around for circulant; constant along each diagonal for Toeplitz); the matrix form of convolution with a fixed kernel (§20.7, §21).
- **[Diagonalization](https://en.wikipedia.org/wiki/Diagonalizable_matrix) / eigenbasis** — choosing a basis of [eigenvectors](https://en.wikipedia.org/wiki/Eigenvalues_and_eigenvectors) (vectors a matrix only scales) so the matrix becomes diagonal; the Fourier basis diagonalizes every circulant matrix, with the kernel's DFT as eigenvalues, which is the convolution theorem (§21).

## Week 2 — Digital Photography I (ray optics, aperture, sensor)
*(full explanations in [`week2-study-notes.md`](./week2-study-notes.md); this is the lookup-speed version)*

- **[Ray optics](https://en.wikipedia.org/wiki/Geometrical_optics)** — modeling light as straight-line rays, ignoring wave effects — the assumption behind pinhole-camera geometry (HW1) and the thin lens model (§1, §5).
- **[Condition number](https://en.wikipedia.org/wiki/Condition_number)** — largest ÷ smallest [singular value](https://en.wikipedia.org/wiki/Singular_value) of a matrix: how much measurement errors can be amplified when inverting it; about 2.0 × 10⁶ for a toy bare sensor, exactly 1 for an ideal pinhole (§1).
- **Pinhole camera / [camera obscura](https://en.wikipedia.org/wiki/Camera_obscura)** — a barrier with a single small opening that lets only one ray per scene point reach the sensor, forming an inverted, scaled image (§2).
- **Focal length (f)** — the distance from a pinhole or lens to the plane where a sharp image forms; an **intrinsic** property fixed at manufacture, not something a photographer adjusts by moving anything (§2, §5.2).
- **[Homogeneous coordinates](https://en.wikipedia.org/wiki/Homogeneous_coordinates)** — appending a 1 to a point, (X, Y, Z, 1), so perspective projection becomes a linear matrix product followed by one division by depth; the pinhole's 3×4 camera matrix (§2).
- **[Rank](https://en.wikipedia.org/wiki/Rank_(linear_algebra))** — the number of independent directions a matrix's output can span; the pinhole camera matrix has rank 3 (depth is lost), and a 4×4 Bayer patch's 16×48 selection matrix has rank 16 (§2, §14).
- **Optimal pinhole diameter** — the pinhole size that minimizes total image blur by balancing geometric blur (grows with diameter *d*) against diffraction spread (shrinks with *d*): d = 2√(fλ), where *f* is the pinhole-to-image-plane distance and λ is the wavelength of light (§3.1).
- **[Refraction](https://en.wikipedia.org/wiki/Refraction)** — the bending of light at a boundary between two materials of different optical density; the mechanism a lens uses to redirect rays (§5).
- **Object distance (S) vs. sensor distance (S′)** — S is how far the actual subject sits from the lens, a property of the *scene*; S′ is how far the lens sits from the sensor, a property of the *setup*, adjusted by the focus ring. The thin lens equation ties the two to the (intrinsic) focal length; "focusing" means physically changing S′ until it matches what the equation demands for the S you want sharp (§5.1–5.3–4.3).
- **Thin lens model / Gaussian lens formula** — a simplified lens model (zero thickness) built on two assumptions (center rays pass straight through; parallel rays converge at the focal plane), giving the thin lens equation 1/S + 1/S′ = 1/f, derived from two similar-triangle ray relations (§5.1).
- **Magnification (m)** — the ratio of image height to object height produced by a lens, m = (S′ − f)/f = S′/S (§5.1).
- **[Ray transfer (ABCD) matrix](https://en.wikipedia.org/wiki/Ray_transfer_matrix_analysis)** — a 2×2 matrix acting on a ray's (height, angle): travel by L is [[1, L], [0, 1]], a thin lens is [[1, 0], [−1/f, 1]], and the thin lens equation is the condition that their product's top-right entry is 0 (§5.1).
- **Aberrations** (spherical, [chromatic](https://en.wikipedia.org/wiki/Chromatic_aberration), oblique/coma/distortion) — systematic deviations from ideal thin-lens focusing, caused respectively by spherical (not hyperbolic) lens shapes, wavelength-dependent refraction (dispersion), and off-axis geometry (§6).
- **[Aperture](https://en.wikipedia.org/wiki/Aperture)** — the opening controlling how much light enters a lens or pinhole; analogous to the iris/pupil. Deepened here with the f-number/stops formalism (§8).
- **[Field of view (FOV)](https://en.wikipedia.org/wiki/Field_of_view)** — the angular extent of scene captured, set by focal length and sensor size; the camera analog of Week 1's eye FOV (§10).
- **[f-number](https://en.wikipedia.org/wiki/F-number)** — ratio of focal length to aperture diameter (N = f/D); smaller means more light and shallower depth of field (§8).
- **Stop** — a change in light by a factor of 2×, the standard unit for spacing aperture (and exposure) settings; the same unit as Week 1's dynamic-range f-stops (§8).
- **Exposure compensation / EV** — a camera dial offsetting the meter's pick by a number of stops (Week 1 §14, Week 4 §2.3); absolute exposure value also labels an aperture/shutter combination, whose aperture half is explained in Week 2 §8.
- **Defocus / actual object distance (O)** — a scene point at actual distance O ≠ the currently-focused distance S has rays that converge before or after the sensor plane, landing as a blurred circle of confusion instead of a sharp point; never happens with an ideal pinhole (§9.1).
- **[Circle of confusion](https://en.wikipedia.org/wiki/Circle_of_confusion)** — the blur disc a defocused point forms on the sensor, c = m·D·|O − S|/O, derived from two similar-triangle relations tying the aperture, the focused distance S, and the actual distance O (§9.2).
- **[Depth of field](https://en.wikipedia.org/wiki/Depth_of_field)** — the range of actual object distances whose circle of confusion stays below an acceptable (pixel-set) threshold ε, DOF ≈ 2εS/(mD) — centered on the focused distance S, not a free "actual distance"; the range's exact edges are its near and far distances, O_near = S/(1+k) and O_far = S/(1-k) with k = ε/(mD) (§10.1, §10.3).
- **[Pixel pitch](https://en.wikipedia.org/wiki/Pixel_pitch)** — the center-to-center spacing of sensor pixels, a length (sensor width ÷ pixel count across it, typically a few µm); converts a blur threshold stated in pixels into the length the circle-of-confusion and depth-of-field formulas need (§10.2).
- **Hyperfocal distance (H)** — the focus distance that extends the far edge of the depth of field to infinity, H = f²/(Nc), where this c is the fixed acceptable-blur threshold, not the general circle-of-confusion variable (§11); focusing at H makes the near edge of the depth of field exactly H/2 (evaluating §10.3's near-distance formula at k=1).
- **Diffraction limit / [numerical aperture](https://en.wikipedia.org/wiki/Numerical_aperture) (NA)** — the smallest resolvable spot size set by diffraction alone (Abbe's formula, d ≈ λ/(2·NA) ≈ λN); trades off against depth of field via f-number (§3, §12).
- **[Bokeh](https://en.wikipedia.org/wiki/Bokeh)** — the look of out-of-focus blur; a defocused point becomes a copy of the aperture's outline (disc, polygon, cat's-eye, donut), size c ≈ (f²/N)|1/S − 1/O|; smooth vs. busy depends on the disc's intensity profile (§13).
- **Apodization** — fading an aperture's transmission toward its rim so the blur disc has soft edges (smooth bokeh), at the cost of some light (§13.3).
- **Portrait mode / computational bokeh** — a depth map plus per-pixel synthetic disc blur imitating the optical bokeh that a phone's tiny lens cannot produce (§13.4).
- **[Time of flight (ToF)](https://en.wikipedia.org/wiki/Time_of_flight) / [LiDAR](https://en.wikipedia.org/wiki/Lidar)** — measuring distance as light's round-trip delay, d = c_light·Δt/2 (3 m ≈ 20 ns); gives phones a direct depth map for portrait mode (§13.4; Week 4 §5, §21.3).
- **Sensor** — the chip converting incident light into an electrical signal — the camera's "retina" (§14).
- **[Photoelectric effect](https://en.wikipedia.org/wiki/Photoelectric_effect)** — a photon striking a photodiode knocking loose an electron; the basic photon-to-signal conversion inside every pixel (§14).
- **[Quantum efficiency](https://en.wikipedia.org/wiki/Quantum_efficiency) / fill factor** — the fraction of incoming photons actually converted to signal, and the fraction of a pixel's area that is light-sensitive, respectively (§14).
- **[Underdetermined system](https://en.wikipedia.org/wiki/Underdetermined_system)** — fewer equations (measurements) than unknowns, so infinitely many solutions fit the data; the Bayer mosaic (16 measurements of 48 unknowns in a 4×4 patch) is one, resolved only by adding assumptions (§14).
- **Selection matrix** — a matrix whose every row holds a single 1 and zeros elsewhere, picking out one entry of the input; the color filter array written as a matrix (§14).
- **[CCD](https://en.wikipedia.org/wiki/Charge-coupled_device) / [CMOS](https://en.wikipedia.org/wiki/CMOS_sensor)** — two sensor architectures for converting and reading out pixel charge; CCD trades speed/cost for sensitivity/noise, CMOS the reverse (§15).
- **[Rolling shutter](https://en.wikipedia.org/wiki/Rolling_shutter) / global shutter** — row-by-row vs. all-at-once pixel exposure timing; rolling shutter can produce motion/flicker banding (e.g. 120 Hz AC-light flicker) but can also be exploited as a fine-grained temporal sensor (§16).
- **Bit depth** — the number of discrete digital levels a sensor's ADC can output (12–14 bits RAW vs. 8 bits JPEG), an additional cap on dynamic range beyond the physical noise floor (§17, §20).
- **Noise** — the random deviation of a measured pixel value from its expected value (mean); like the jitter in repeated kitchen-scale readings of the same apple (§18.1).
- **Variance / standard deviation (first definition)** — variance σ² is the average *squared* deviation from the mean; standard deviation σ is its square root, the typical wobble in the pixel's own units. Independent noise variances add (§18.1; derived in Week 4 §3).
- **Independent (uncorrelated) noise** — one random draw tells you nothing about another (e.g. different frames' readouts); the condition under which variances add (§18.1).
- **Electrons vs. digital numbers (DN)** — noise is easiest to reason about in electrons; the ADC converts to integer DN with a conversion gain *g* (DN = *g* × electrons; σ scales by *g*, variance by *g*²) (§18.2).
- **[Gaussian noise](https://en.wikipedia.org/wiki/Gaussian_noise)** — additive, signal-independent sensor noise from thermal/read/amplifier sources (§18).
- **[Shot noise](https://en.wikipedia.org/wiki/Shot_noise) / [read noise](https://en.wikipedia.org/wiki/Image_noise#Read_noise)** — shot noise: fundamental, signal-dependent randomness in photon arrival counts (Poisson-distributed, standard deviation = √N). Read noise: added by the sensor's own readout electronics, signal-independent (§18).
- **Poisson distribution** — the distribution of counts of randomly-timed independent events at a steady average rate (raindrops in a bucket, photon arrivals); its variance equals its mean (§18.4).
- **Dark current / dark current noise** — electrons freed by heat in the photodiode even with no light; mean rate *D* e⁻/pixel/s, Poisson-random so variance *D·t*; the mean can be subtracted with a dark frame, the randomness cannot (§18.3).
- **Quantization noise** — rounding error when the ADC maps a continuous voltage to integer digital numbers; uniform in ±½ step, variance Δ²/12 for step Δ (§18.5).
- **Fixed-pattern noise** — repeatable pixel-to-pixel offset/gain differences from manufacturing; the same in every shot, so it does not average down across frames (§18.3).
- **Dark frame** — an exposure with the lens capped, used to measure and subtract dark current's mean and fixed-pattern offsets (§18.5).
- **[Signal-to-noise ratio (SNR)](https://en.wikipedia.org/wiki/Signal-to-noise_ratio)** — mean signal divided by its standard deviation; combines shot noise, dark current, and read noise into one formula (§19).

## Week 3 — Digital Photography II (color science, ISP, demosaicking, denoising)
*(full explanations in [`week3-study-notes.md`](./week3-study-notes.md); this is the lookup-speed version)*

- **[Spectral sensitivity function (SSF)](https://en.wikipedia.org/wiki/Spectral_sensitivity)** — a sensor's (eye cone or camera pixel's) per-wavelength responsiveness; its response to incident light is the integral of the light's spectral power distribution weighted by this function, R = ∫Φ(λ)f(λ)dλ (§2).
- **Retinal (tristimulus) color space / [metamerism](https://en.wikipedia.org/wiki/Metamerism_(color))** — the 3D space of achievable (S,M,L) cone responses; monochromatic light traces a "lasso curve" confined to the positive octant, and varying its strength sweeps out a convex cone with a horseshoe-shaped cross-section. Metamers (Week 1 §6) are physically different spectra landing on the same interior point of this cone (§3).
- **[Conic hull](https://en.wikipedia.org/wiki/Conical_combination) / [convex hull](https://en.wikipedia.org/wiki/Convex_hull)** — all non-negative combinations of a set of vectors (conic hull), or all non-negative combinations whose weights also sum to 1 (convex hull); the achievable-color cone is the conic hull of the lasso vectors, and a gamut triangle is the convex hull of three primary chromaticities (§3, §7).
- **[CIE color matching functions](https://en.wikipedia.org/wiki/CIE_1931_color_space#Color_matching)** — the weights of three fixed primaries needed to visually match each pure spectral color; some matches require a negative coefficient, recorded when a primary had to be added to the test side instead of the primary side (§4).
- **[Standard observer](https://en.wikipedia.org/wiki/CIE_1931_color_space#CIE_standard_observer)** — an idealized "average" viewer built by pooling color-matching data from a small panel of real observers; formally it *is* its three color matching functions, and every CIE number describes what this averaged viewer would report (§4).
- **[Luminous efficiency function V(λ)](https://en.wikipedia.org/wiki/Luminous_efficiency_function)** — the eye's relative brightness sensitivity at each wavelength (peak normalized to 1, in the green); CIE XYZ's Y coordinate was defined so its matching function equals V(λ), which makes Y luminance (§5).
- **[CIE XYZ](https://en.wikipedia.org/wiki/CIE_1931_color_space) / CIE RGB** — two equivalent tristimulus bases for color: CIE RGB uses physically realizable primaries but needs negative coordinates for some colors; CIE XYZ guarantees non-negative coordinates for every color but its "primaries" aren't physically realizable light. No basis can have both (§5).
- **[CIE xy chromaticity diagram](https://en.wikipedia.org/wiki/CIE_1931_color_space#Chromaticity_diagram)** — a 2D projection of 3D CIE XYZ (x=X/(X+Y+Z), y=Y/(X+Y+Z)) that discards luminance and keeps only hue/saturation (§6).
- **[Color gamut](https://en.wikipedia.org/wiki/Gamut)** — the set of colors a device can reproduce; for any 3 real primaries this is exactly the triangle of their chromaticity coordinates (a convex combination of 3 points), e.g. the sRGB gamut. Points outside the triangle need a negative coordinate and are unreproducible by that primary set (§7–§8).
- **[Barycentric coordinates](https://en.wikipedia.org/wiki/Barycentric_coordinate_system)** — the weights expressing a point as a weighted average of a triangle's corners; all positive means inside (D65 white in sRGB: (0.2120, 0.3922, 0.3959)), any negative means outside (§7).
- **[Display P3](https://en.wikipedia.org/wiki/DCI-P3)** — a wide-gamut RGB standard used by many phone/laptop screens: the cinema DCI-P3 primaries paired with a D65 white; the same RGB numbers mean a different color in Display P3 than in sRGB (§8).
- **[Image signal processor (ISP) pipeline](https://en.wikipedia.org/wiki/Image_processor)** — the stage sequence turning a RAW Bayer image into a finished photo: demosaicking → denoising → gamut mapping → gamma correction → compression, plus dead-pixel removal, dark-frame subtraction, lens correction, and sharpening (§9).
- **[Exif](https://en.wikipedia.org/wiki/Exif)** — capture metadata (exposure, aperture, ISO, timestamp, lens) stored alongside an image's pixel data (§9).
- **[Gamma correction](https://en.wikipedia.org/wiki/Gamma_correction) / [sRGB](https://en.wikipedia.org/wiki/SRGB)** — encoding linear sensor intensity with a power-law-like curve so finite bit-depth code steps match perceived (not physical) brightness steps; PS2's simplified form is I→I^(1/2.2), while the sRGB standard uses an exact piecewise linear/power-law formula (threshold 0.0031308, exponent 1/2.4, constant α=0.055) (§10).
- **[Denoising](https://en.wikipedia.org/wiki/Noise_reduction)** — computationally removing sensor noise after capture; most methods specialize one weighted-average framework, i_denoised(x) = (1/normalizer)·Σw(x,x')·i_noisy(x'), differing only in how the weight w is defined (§12.1).
- **[PSNR](https://en.wikipedia.org/wiki/Peak_signal-to-noise_ratio) / MSE** — mean squared error (averaged over pixels and color channels) and its log-scale, max-value-normalized ratio, PSNR=10·log₁₀(max²/MSE); the metric HW2 uses to numerically compare demosaicking methods (§13).
- **[Identity matrix](https://en.wikipedia.org/wiki/Identity_matrix) Id** — the matrix that leaves every vector unchanged (1s on the diagonal, 0s elsewhere); written Id in the Week 3 notes so it never clashes with the image I (§13, §17).
- **[Demosaicking](https://en.wikipedia.org/wiki/Demosaicing)** — reconstructing full color from a Bayer sensor where each pixel measured only one channel; naive per-channel averaging (§14.1) improves through chrominance low-pass filtering (§14.3) and edge-directed methods (§14.4) to Malvar-He-Cutler (§14.5).
- **[Optical low-pass filter (OLPF)](https://en.wikipedia.org/wiki/Optical_low-pass_filter)** — a birefringent glass layer in front of a sensor that pre-blurs incoming light to soften Bayer-sampling aliasing, at the cost of resolution (§14.2).
- **Channel disagreement / false color** (also: color artifacts, color fringing; color moiré for the repeating-pattern version, color noise or chroma noise for the random version, color bleeding for the JPEG version) — a pixel's R, G, B values disagree more than the scene's do, so the pixel shows a color the scene never had (a neutral pixel has R = G = B). Week 3 meets it seven times: demosaicking edges (§14.1), aliasing (§14.2), misaligned or sequential capture (§15), per-channel noise (§16.1), per-channel gamut clipping (§18), JPEG chroma subsampling (§19) and chromatic aberration (§21); recap table in §22.
- **[Y′CbCr](https://en.wikipedia.org/wiki/YCbCr)** — a luma (Y′) + chrominance (Cb, Cr) color representation, related to RGB by a fixed matrix and offset; used to filter only chrominance during demosaicking (§14.3) and to subsample only chrominance in JPEG (§19), since human vision is far more sensitive to luminance sharpness.
- **[Affine map](https://en.wikipedia.org/wiki/Affine_transformation)** — a linear map plus a constant shift, u = Mv + o; RGB → Y′CbCr is affine because of its (16, 128, 128) offset, and is undone by v = M⁻¹(u − o) (§14.3).
- **Malvar-He-Cutler demosaicking** — a linear demosaicking filter that adds a gain times a same-location, cross-channel gradient (Laplacian) correction to the naive interpolation estimate; published gains α=1/2, β=5/8, γ=3/4 (§14.5).
- **[Bilateral filter](https://en.wikipedia.org/wiki/Bilateral_filter)** (Tomasi & Manduchi, 1998) — a denoising filter weighting by the product of a spatial Gaussian and an intensity-difference Gaussian, so it smooths noise within a region but not across an edge ("edge-aware smoothing") (§16.2).
- **[Non-local means](https://en.wikipedia.org/wiki/Non-local_means)** (Buades, Coll & Morel, 2005) — a denoising filter weighting by patch similarity rather than single-pixel intensity, searching a bounded window and exploiting image self-similarity regardless of spatial distance (§16.3).
- **NLM filtering parameter *h* / normalizer *Z(i)*** — HW2's symbols for non-local means: *h* sets how different two patches may be before their weight collapses (*h*² = 2σ² in these notes' form), and *Z(i)* is the sum of the weights, dividing by which makes them a true weighted average (§16.3).
- **[BM3D](https://en.wikipedia.org/wiki/Block-matching_and_3D_filtering)** — a state-of-the-art (not HW2-required) denoising method: group similar patches into 3D blocks and collaboratively filter each block via a DCT transform, coefficient thresholding, and inverse transform (§16.5).
- **[Unsharp masking](https://en.wikipedia.org/wiki/Unsharp_masking)** — sharpening by adding back an amplified detail layer: sharpened = I + k·(I − blur(I)), with strength k chosen by the user (§17).
- **Detail layer** — I − blur(I): the high image-frequency part of an image (edges and texture) that a blur removed; near zero in smooth regions (§17).
- **Halo artifact** — the bright/dark outline hugging a strong edge after sharpening, caused by overshoot and undershoot when the edge itself lands in the detail layer (e.g. with a Gaussian blur); an edge-preserving bilateral blur largely avoids it (§17).
- **Gamut mapping** — converting a camera's native color gamut to a standard gamut (typically sRGB) via a camera XYZ → CIE XYZ → sRGB chain (§18).
- **Gamut clipping** — the simplest gamut-mapping strategy: clamp each linear RGB channel of an out-of-gamut color to [0, 1] independently; cheap, but shifts hue/brightness and flattens saturated gradations into one patch (§18).
- **Gamut compression** — a smoother gamut-mapping strategy that moves out-of-gamut colors inward (e.g. desaturating toward a gray of the same luminance), often nudging nearby in-gamut colors too so shades stay distinguishable; one source of camera "modes" (§18).
- **[Chroma subsampling](https://en.wikipedia.org/wiki/Chroma_subsampling)** — storing the chroma channels (Cb, Cr) at lower spatial resolution than luma (Y′), e.g. JPEG's 4:2:2 and 4:2:0, because the eye resolves fine color detail far less well than fine brightness detail (§11, §19).
- **[JPEG](https://en.wikipedia.org/wiki/JPEG) / [DCT](https://en.wikipedia.org/wiki/Discrete_cosine_transform)** — the standard lossy image compression pipeline: RGB→Y′CbCr, chroma subsampling (4:4:4/4:2:2/4:2:0), 8×8-block discrete cosine transform, coefficient quantization, and entropy/run-length coding (§19).
- **[Orthonormal basis](https://en.wikipedia.org/wiki/Orthonormal_basis) (DCT)** — a basis of unit-length, mutually perpendicular vectors, so the inverse change of basis is just the transpose; JPEG's 64 8×8 DCT cosine patterns form one (§19).
- **[RAW file](https://en.wikipedia.org/wiki/Raw_image_format) / [dcraw](https://en.wikipedia.org/wiki/Dcraw)** — a camera's container for its nearly unprocessed sensor mosaic plus the metadata needed to interpret it (filter pattern, black/white levels, white-balance gains, color matrix); dcraw is the classic command-line decoder, and rawpy the Python wrapper around its successor library, LibRaw (§20).
- **Black level / white level** — the fixed electronic offset a no-light pixel reads (subtracted first) and the saturated maximum (divided by, after subtraction) that together put RAW values on a [0, 1] linear scale (§20).
- **[White balance](https://en.wikipedia.org/wiki/Color_balance)** — per-channel gains that make a neutral gray object come out with R = G = B, removing the light source's color cast; a diagonal matrix acting on (R, G, B) (§20).
- **[Deconvolution](https://en.wikipedia.org/wiki/Deconvolution)** (defined in Week 1 §23; this is the Week 3 echo) — computationally undoing a known blur; Week 3 only previews this with one example slide (blur sources: defocus, geometric distortion, spherical/chromatic aberration, coma) and no formula — full treatment, and the inverse-problem framing, is Week 5–6's subject.

## Week 4 — Great Ideas in Computational Photography
*(full explanations in [`week4-study-notes.md`](./week4-study-notes.md); this is the lookup-speed version)*

- **[Exposure](https://en.wikipedia.org/wiki/Exposure_(photography))** — total light collected per unit sensor area, H = E·t ∝ L·t/N², set by exposure time and aperture (and scene brightness); ISO scales the recorded image's brightness but does not change H (§2.1–2.2).
- **Exposure time / shutter speed / shutter time** — three names for one setting: how long the shutter lets each pixel collect light (e.g. 1/500 s, 2 s, "bulb"); a "fast shutter speed" is a short exposure time (§2.1).
- **[Shutter](https://en.wikipedia.org/wiki/Shutter_(photography))** — the mechanical curtain or electronic reset/readout that starts and stops light collection (§2.1).
- **Equivalent exposures / reciprocity** — (time, aperture) pairs with the same t/N² deliver the same exposure; they differ in motion blur and depth of field instead of brightness (§2.2–2.3).
- **[Exposure value (EV)](https://en.wikipedia.org/wiki/Exposure_value)** — EV = log₂(N²/t), a single number labeling a family of equivalent exposures; one EV = one stop (§2.3).
- **Full-well capacity / saturation ([clipping](https://en.wikipedia.org/wiki/Clipping_(photography)))** — the maximum charge a pixel can hold; overexposed pixels hit it and all read the same maximum, losing detail irrecoverably (§2.4).
- **Underexposure / overexposure** — too little light (signal buried in the noise floor) vs. too much (highlights saturate); correct exposure fits the scene inside the sensor's dynamic range (§2.4).
- **[ISO](https://en.wikipedia.org/wiki/Film_speed)** — a sensor gain setting, usually applied before the ADC, that amplifies signal (and noise) without collecting more light (§2.5).
- **Variance / standard deviation** — the average squared deviation of a noisy value from its mean, and its square root (the typical size of the wobble); independent noise variances add, and averaging K independent frames divides the variance by K: the K comes from the K terms in the summed variance, and K² from squaring the 1/K scale factor (§3; first defined in Week 2 §18).
- **Poisson sum rule** — Pois(λ₁) + Pois(λ₂) = Pois(λ₁ + λ₂): adding photon counts from separate frames is statistically the same as counting once over the combined light; a Poisson variable's mean and variance are both λ (§3).
- **[Motion blur](https://en.wikipedia.org/wiki/Motion_blur)** — streaking from scene or camera motion during the exposure; streak length = image-plane speed × exposure time; mathematically a convolution with a box kernel (§4.3, §23.1).
- **[Burst photography](https://en.wikipedia.org/wiki/Burst_mode_(photography))** — capturing many short exposures and merging them, avoiding blur at the cost of paying read noise once per frame (§4.5).
- **Active vs. passive sensing / range gating** — a passive camera collects existing light; an active sensor (LiDAR, ToF camera) supplies its own; range gating opens the detector only during a nanosecond window when the laser echo can arrive, an ultra-short exposure that rejects ambient light (§5).
- **Integration time (ToF)** — a time-of-flight camera's name for exposure time: longer gives less noisy depth but more motion artifacts and saturation (§5.4).
- **[Light metering](https://en.wikipedia.org/wiki/Light_meter)** — measuring a scene's overall brightness so the camera can pick an exposure setting; conventionally assumes the frame averages to about **18% reflectance** (the "key," the same mid-gray convention as Week 3 §10's gamma example; real meter calibration works out to roughly 12–18%), which is exactly why metering can be "fooled" by scenes far brighter or darker than 18% gray (snow, a coal pile) (§6).
- **[Neutral density (ND) filter](https://en.wikipedia.org/wiki/Neutral-density_filter)** — darkened glass/film in front of the lens that attenuates all wavelengths roughly equally, reducing light reaching the sensor without shifting color; strength measured in [optical density](https://en.wikipedia.org/wiki/Optical_density), OD = log₁₀(1/transmittance) (§8.1).
- **Calibration** — measuring things whose true values you already know, recording what an instrument reports for each, and thereby learning the mapping from reading to truth (e.g. weighing known reference weights on a kitchen scale; a thermometer in ice water at 0 °C) (§9.1).
- **Calibration target** — an object, scene or setup whose true physical values are known in advance, used as the reference an instrument's reading is compared against; for a camera: a grayscale step chart or ColorChecker (known reflectances), a light at known intensity, or an exposure-time sweep (known relative light by construction) (§9.1, §9.3).
- **Radiometric calibration** — measuring, and then undoing, a camera's response curve (its mapping from true light amount to recorded pixel value, bent by saturation, a noise floor and the in-camera tone curve) so recorded pixel values become proportional to light before HDR merging (§9).
- **Response curve (camera response function, CRF)** — the plot or function *f* taking true light amount (scene flux times exposure time) to the pixel value a camera writes out; its inverse *f*⁻¹ linearizes pixel values (§9.1, §11).
- **Tone reproduction curve** — the nonlinear function *f* a camera silently applies to its raw linear sensor reading before producing a viewable image (e.g. JPEG); a good generic fallback is a power law with γ ≈ 1/2.2 (§9.1, §9.4).
- **[ColorChecker](https://en.wikipedia.org/wiki/ColorChecker)** — a standardized chart of patches with known reflectance; its bottom row of six neutral grays (reflectance about 90% down to about 3%, optical density 0.05 to 1.50, not evenly spaced in log-reflectance) is one target used to calibrate a camera's tone reproduction curve (§9.3).
- **sRGB decoding** — undoing the standard sRGB display curve (divide the 8-bit code by 255, then apply a short linear segment near black and a roughly 2.2–2.4 power law elsewhere) to get linear values proportional to scene light (§9.5).
- **Triangle (hat) weight** — Debevec's HDR merge weight w(z) = 1 − |2z − 1| = 2·min(z, 1 − z): zero for black and saturated values, weight 1 at mid-gray z = 0.5, the straight-line alternative to the Gaussian weight (§10.4).
- **Weight image** — the per-pixel confidence weights of one exposure shown as a grayscale image (bright = trusted), used to check which exposure covers which part of the scene (§10.4).
- **Machine epsilon (ε) in log** — a tiny constant (the smallest relative float spacing) added before taking a logarithm so zero-valued pixels do not produce −∞ or NaN in the HDR merge (§10.5).
- **Camera response function (CRF)** — the curve a camera applies between scene light and stored pixel value (the f of §9.2, or its inverse by convention); estimated by a linear least-squares fit in the Debevec–Malik method that OpenCV implements (§9.2, §11).
- **HDR file formats — [.pfm](https://en.wikipedia.org/wiki/Netpbm#File_formats), [Radiance .hdr](https://en.wikipedia.org/wiki/RGBE_image_format), [OpenEXR](https://en.wikipedia.org/wiki/OpenEXR)** — floating-point image formats needed because merged HDR pixel values span many orders of magnitude and would clip in a fixed-integer format; .hdr's trick is a single 8-bit exponent shared across all three color channels, so a pixel takes 32 bits instead of the 96 bits of three 32-bit floats (§12.3).
- **Light probe / [environment map](https://en.wikipedia.org/wiki/Reflection_mapping)** — an HDR photograph of a mirrored chrome sphere placed in a scene, capturing the entire surrounding illumination in one image; used for image-based relighting of synthetic objects (§12.4).
- **Tone** — the brightness level of a pixel or region on the dark-to-light scale (usually luminance); in music a tone is a position on a pitch scale, in an image a position on a brightness scale. Not the color cast sense of "warm tone" (§13.1).
- **Tonal range** — the span of tones in an image, from its darkest to its brightest region (§13.1).
- **Tone curve** — a function mapping input tone to output tone; the in-camera one is baked in at capture and undone by calibration (§9), whereas a tonemapping curve is applied by you after HDR merging (§13.1, §14).
- **[Tone mapping](https://en.wikipedia.org/wiki/Tone_mapping)** — applying a tone curve (or more elaborate local operator) to fit an image's huge tonal range into the small one a display can show while keeping the look of contrast and detail (analogy: a long scroll onto a postcard); compressing an image's (HDR or LDR) intensity values into the narrower range an actual display can show; progresses from a naive per-channel curve through intensity-only (xyY), edge-aware, and gradient-domain variants to avoid color washout and halo artifacts in turn (§13–§15).
- **Gamma tonemapper (s·I)^γ** — the simplest global tonemap: scale by s, raise to a power γ < 1 to lift shadows, clip to [0, 1] (§14.1).
- **Global vs. local tonemapping** — a global operator maps each pixel by its own value alone; a local operator also uses the pixel's neighbors to preserve local contrast (§14.2).
- **[xyY](https://en.wikipedia.org/wiki/CIE_1931_color_space#CIE_xyY_color_space)** — a reparameterization of Week 3 §6's CIE xy chromaticity diagram that adds back a luminance axis Y; tonemapping compresses Y alone and leaves xy (chromaticity) untouched, which is what keeps color-aware tonemapping from washing out hue/saturation (§15).
- **[HDR imaging](https://en.wikipedia.org/wiki/High_dynamic_range#Capture)** — precisely, producing a *radiometrically linear* image free of over-/under-exposure artifacts, via some combination of a single well-exposed RAW capture, radiometric calibration (§9), and/or bracketing-and-merging multiple exposures (§8, §10); the lecture is explicit that this is **distinct** from tonemapping — HDR imaging compensates for sensor limitations, tonemapping for display limitations — even though consumer "HDR mode" workflows routinely run both together (§16).
- **PSF ([point spread function](https://en.wikipedia.org/wiki/Point_spread_function))** — the blob a single point of light forms after passing through an optical system (a disc for a finite pinhole, a circle of confusion for a defocused lens, an Airy pattern at the diffraction limit); for a shift-invariant system, the whole image is the convolution of the ideal sharp image with this kernel. The convolution it relies on is built from scratch in Week 1 §20. Introduced and defined in full here; Week 5 formalizes it further in the deconvolution/Wiener-filter context (§18.1).
- **[OTF (optical transfer function)](https://en.wikipedia.org/wiki/Optical_transfer_function)** — the 2D Fourier transform of the PSF; reports, frequency by frequency, how much of each spatial frequency survives the imaging system. A PSF/OTF is **broadband** when its OTF has no exact zero crossings — equivalently, its convolution matrix has a trivial null space and is, in principle, fully invertible (§18.2, §19.3).
- **Coded aperture** — replacing a camera's plain circular aperture stop (or its refractive optics) with a deliberately patterned mask or phase element, chosen so the resulting point spread function's Fourier transform has no exact-zero frequencies ("broadband"), preserving information a plain aperture's blur would destroy (§19).
- **Extended depth of field (EDOF)** — an image sharp at every depth simultaneously, produced by deliberately blurring everything with a *depth-invariant*, broadband PSF (via focal sweep or wavefront coding) and then deconvolving with one shared kernel (§20).
- **[Wavefront coding](https://en.wikipedia.org/wiki/Wavefront_coding)** — altering a lens's refractive/diffractive optics (rather than attenuating light with a mask) so a point source's rays no longer converge to a sharp focus at any one plane, giving an approximately depth-invariant PSF with no moving parts (§20.2).
- **Focal sweep** — physically moving the sensor or focal plane through a range of positions during one exposure so every scene depth ends up blurred by approximately the same time-integrated kernel, giving a depth-invariant PSF (§20.2–§20.3).
- **Monocular depth estimation** — recovering per-pixel depth from a single ordinary 2D photograph, either from learned pictorial cues (relative size, occlusion, perspective) or from a coded aperture's depth-dependent PSF shape/orientation (§21). *(No precise Wikipedia article covers this specific technique combination — left unlinked.)*
- **[Flutter shutter](https://en.wikipedia.org/wiki/Coded_exposure_photography)** — flickering the shutter open/closed in a coded temporal pattern during one exposure, replacing the ordinary box blur kernel's zero-crossing sinc spectrum with a broadband (zero-free) spectrum, so the resulting motion blur becomes invertible (§23).
- **Duty cycle** — the fraction of an exposure during which a shutter (here, a flutter shutter) is open; it sets how much light a coded exposure collects (§23.3).
- **Parabolic sweep / motion-invariant photography** — moving the camera itself along a parabolic (constantly accelerating) trajectory during exposure so every scene object, regardless of its own velocity, ends up blurred by the same motion-invariant kernel, enabling one shared deconvolution kernel across a whole frame (§24). *(No Wikipedia article exists for this specific technique — left unlinked.)*

## Week 5 — Sampling, Linear Systems, Deconvolution
*(full explanations in [`week5-study-notes.md`](./week5-study-notes.md); this is the lookup-speed version)*

**The Fourier toolkit**
- **Temporal / spatial / image frequency** — how often something repeats per second (Hz), per millimeter (cycles/mm), or per stored pixel (cycles/pixel); the wavelength of light is a separate quantity (§1).
- **Amplitude, frequency, [phase](https://en.wikipedia.org/wiki/Phase_(waves))** — a wave A·cos(2πξx + φ) has height A, ξ cycles per unit length (period 1/ξ) and sideways shift φ (§2.1).
- **[Complex number](https://en.wikipedia.org/wiki/Complex_number) / magnitude / angle / [conjugate](https://en.wikipedia.org/wiki/Complex_conjugate)** — a pair (a, b) drawn as an arrow; multiplying complex numbers multiplies lengths and adds angles; the conjugate mirrors the arrow (§2.2).
- **[Euler's formula](https://en.wikipedia.org/wiki/Euler%27s_formula)** — e^{jθ} = cos θ + j sin θ: a unit arrow at angle θ, so A·e^{jφ} stores an amplitude and a phase and e^{j2πξx} is a wave of frequency ξ (§2.3).
- **Negative frequency** — the second, oppositely spinning arrow that pairs with +ξ to make a real cosine; not a physical thing (§2.3).
- **[Summation](https://en.wikipedia.org/wiki/Summation) (Σ) / [integral](https://en.wikipedia.org/wiki/Integral) (∫) / index** — Σ_{n=0}^{N−1} x[n] adds a list as the index n runs from 0 to N−1; ∫_a^b f(x) dx adds infinitely thin slices of height f(x) and width dx, i.e. the area under the curve; ∫∫ … dx dy adds over a 2D grid of tiny squares (§2.4).
- **Dummy variable** — the variable after d (or under Σ) that is summed away, so the answer does not depend on it; renaming it changes nothing (§2.4).
- **Pulling constants out / [substitution](https://en.wikipedia.org/wiki/Integration_by_substitution) (change of variables)** — anything not depending on the dummy variable moves outside the integral; renaming u = x/a turns dx into a du, so ∫ f(x/a) dx = a ∫ f(u) du (§2.4).
- **[Fourier transform](https://en.wikipedia.org/wiki/Fourier_transform)** — f̂(ξ) = ∫ f(x) e^{−j2πξx} dx: how much of each wave a signal contains; the inverse adds the waves back and loses nothing (§3.1). In 2D: F(k_x, k_y) = ∫∫ f(x, y) e^{−j2π(k_x x + k_y y)} dx dy, computable as a 1D transform along every row then every column (§3.2).
- **Primal domain / Fourier domain / spectrum** — the slides' names for the original space-or-time description and the per-frequency description of the same signal; the spectrum is the set of Fourier coefficients (§3.1). Same concept, different names: primal domain = spatial domain (images) = time domain (time signals); Fourier domain = frequency domain = spectral domain (PS4 also says "dual"); the Fourier transform of a signal = its spectrum = its Fourier coefficients.
- **[Grating](https://en.wikipedia.org/wiki/Diffraction_grating)** (in a 2D spectrum) — the parallel-stripe pattern cos(2π(k_x x + k_y y)) that one 2D Fourier coefficient stands for; stripes run perpendicular to (k_x, k_y), with frequency √(k_x² + k_y²); an image is a sum of gratings (§3.2). *(Wikipedia's article covers the optical device; here the word means just the stripe pattern.)*
- **DC component** — the zero-frequency coefficient, equal to the signal's average (times N for the DFT); the bright center of a spectrum picture (§3.2).
- **Conjugate symmetry** — real signals satisfy F(−k) = F(k)*, so a real image's magnitude spectrum looks the same rotated 180° (§3.3).
- **Magnitude vs. phase** — magnitude = how strong each grating is, phase = where its stripes sit; swapping phases between two photos swaps what you recognize, so phase carries the structure (§4).
- **Shift theorem** — F{f(x − d)} = e^{−j2πξd} f̂(ξ): moving a signal sideways by d only turns each coefficient's phase, never changes its magnitude, so all "where" information lives in the phase (§4). *(Covered in the Fourier transform article's properties; no standalone article.)*
- **[Convolution](https://en.wikipedia.org/wiki/Convolution)** — (x ∗ h)[n] = Σ h[m] x[n − m]: stamp a scaled copy of the kernel at every input point and add (§5.1).
- **Kernel / [impulse response](https://en.wikipedia.org/wiki/Impulse_response)** — the weights a convolution slides over the signal; what comes out when a single impulse goes in (for optics, the PSF) (§5.1). Same concept, different names: kernel = convolution kernel = filter kernel = filter = impulse response; for an optical system, the point spread function (PSF), which the slides also call the blur kernel; in code a small kernel is sometimes a mask or stencil (not the Fourier-domain mask of §16). Not every kernel is a PSF (§12.3).
- **[LSI system](https://en.wikipedia.org/wiki/Linear_time-invariant_system)** (linear shift-invariant) — any system where outputs add and scale with inputs and the same rule applies everywhere; every such system is a convolution with its impulse response (§5.1).
- **Normalized kernel** — kernel weights summing to 1, so flat regions keep their brightness and total light is conserved (§5.1, §16.4).
- **[Convolution theorem](https://en.wikipedia.org/wiki/Convolution_theorem)** — F{x ∗ g} = F{x}·F{g}: convolving in one domain is multiplying in the other (§5.2). It runs both ways: F{x·g} = F{x} ∗ F{g}, so multiplying in the primal domain (sampling, cropping) convolves the spectra (§5.3).
- **[Circulant matrix](https://en.wikipedia.org/wiki/Circulant_matrix) / [eigenvector](https://en.wikipedia.org/wiki/Eigenvalues_and_eigenvectors)** — a matrix whose rows are successive cyclic shifts of one row (the form a wrap-around convolution takes); every sampled wave is an eigenvector of it, with the kernel's spectrum as eigenvalue (§5.2).
- **[Modulation](https://en.wikipedia.org/wiki/Modulation)** (multiplying by a wave) — F{f(x)·e^{j2πξ₀x}} = f̂(ξ − ξ₀): multiplying a signal by a pure wave slides its spectrum to ξ₀; the mirror of the shift theorem. Multiplying two cosines gives the sum and difference frequencies (§5.3).
- **[Frequency response](https://en.wikipedia.org/wiki/Frequency_response) / gain** — a kernel's spectrum read as one multiplier (gain) per frequency; for a lens it is the OTF (§5.4, §14).
- **Pass / attenuate / block / amplify** — a frequency with |gain| = 1 is passed; 0 < |gain| < 1 attenuated; gain = 0 blocked (also stopped, rejected, removed); |gain| > 1 amplified (also boosted) (§5.4). Same concept, different names: attenuate = damp = suppress = weaken = roll off (roll-off = a gain that falls gradually as frequency rises).
- **[Decibel](https://en.wikipedia.org/wiki/Decibel) (dB) for gains** — attenuation on a log scale, 20·log₁₀(gain) for amplitudes (10·log₁₀ for powers, Week 3 §13); a gain of 0.5 is about −6 dB (§5.4).
- **[Triangle inequality](https://en.wikipedia.org/wiki/Triangle_inequality)** — a sum of arrows is never longer than the sum of their lengths; it is why a non-negative kernel summing to 1 has |gain| ≤ 1 (§5.4, §14).
- **Non-negative-kernel low-pass rule** — a kernel whose weights are all ≥ 0 and sum to 1 has gain exactly 1 at zero frequency and ≤ 1 everywhere else, so it is a low-pass filter (a blur); negative weights (sharpening, edge detection) break the rule (§5.4).
- **[Dirac delta](https://en.wikipedia.org/wiki/Dirac_delta_function) (impulse)** — zero everywhere except one point, with area 1; its Fourier transform is the constant 1 (§6.1). Same concept, different names: impulse = delta = Dirac delta = unit impulse = δ function; the on-a-grid version (1 at one sample, 0 elsewhere) is the [Kronecker delta](https://en.wikipedia.org/wiki/Kronecker_delta) or discrete impulse; in optics an impulse is a point source.
- **Sifting property** — ∫ f(x) δ(x − a) dx = f(a): multiplying by a shifted impulse picks out one value; it gives F{δ}(ξ) = e^{−j2πξ·0} = 1 for every ξ (§6.1).
- **[Rectangular function](https://en.wikipedia.org/wiki/Rectangular_function) (rect, box) / [sinc](https://en.wikipedia.org/wiki/Sinc_function)** — rect(x) = 1 for |x| < ½; its transform sinc(ξ) = sin(πξ)/(πξ) crosses exactly zero at every nonzero integer, with sinc(0) = 1 (the box's area); this course uses the normalized sinc, with π inside (§6.2).
- **[Triangular function](https://en.wikipedia.org/wiki/Triangular_function) (tent)** — rect ∗ rect; its transform is sinc² (§6.3).
- **[Gaussian function](https://en.wikipedia.org/wiki/Gaussian_function)** — the bell curve; its transform is another Gaussian of width 1/(2πσ), with no ripples or negative values in either domain (§6.4). The optional derivation completes the square in the exponent ([completing the square](https://en.wikipedia.org/wiki/Completing_the_square)) (§6.4).
- **[Dirac comb](https://en.wikipedia.org/wiki/Dirac_comb) (impulse train)** — impulses spaced T apart; its transform is a comb spaced 1/T apart, every spike of height 1/T, since a comb contains every allowed frequency equally (§6.5). Same concept, different names: impulse train = comb = comb function = Dirac comb = Shah function (Ш) = sampling function.
- **Scaling theorem** — stretching a signal by a squeezes its spectrum by a: wide in one domain is narrow in the other (§6.6). *(Covered in the Fourier transform article's properties; no standalone article.)* Derived by the substitution u = x/a (§6.6).

**Sampling and the DFT**
- **[Sampling](https://en.wikipedia.org/wiki/Sampling_(signal_processing)) / sampling rate f_s** — keeping values only every T (f_s = 1/T); in the Fourier domain it adds copies of the spectrum at every multiple of f_s (§7).
- **Sample (noun) / to sample (verb)** — a sample is one measured value of a continuous signal at one position or instant (one pixel value, one audio reading, one LiDAR digitizer tick); to sample is to take such measurements, usually evenly spaced. A pixel value is a sample of the light after averaging over the pixel's area (§7.1).
- **Sampling interval T** — the spacing between consecutive samples (§7.1). Same concept, different names: sampling interval = sampling period = sample spacing; on a sensor, the pixel pitch.
- **Sampling rate f_s = 1/T** — samples per unit time or length (§7.1). Same concept, different names: sampling rate = sampling frequency = sample rate; samples per second (S/s, e.g. 1 GS/s) in LiDAR and electronics; dpi/ppi for displays and printers.
- **[Resampling](https://en.wikipedia.org/wiki/Sample-rate_conversion)** — computing samples on a new grid from samples you already have (resizing, rotating, warping an image) (§7.1).
- **Subsampling** — the simplest downsampling: keep every D-th sample and discard the rest, with no filtering (`I[::4, ::4]`) (§7.1).
- **[Decimation](https://en.wikipedia.org/wiki/Downsampling_(signal_processing))** — downsampling by a whole-number factor D; in signal-processing usage it includes a low-pass filter before discarding samples (§7.1, §19).
- **[Interpolation](https://en.wikipedia.org/wiki/Interpolation)** — estimating values between existing samples; how upsampling fills in new samples (§7.1).
- **[Oversampling](https://en.wikipedia.org/wiki/Oversampling) / [undersampling](https://en.wikipedia.org/wiki/Undersampling)** — sampling faster / slower than the signal needs (the Nyquist rate); undersampling causes aliasing (§7.1, §8).
- **"Sample" in the statistical sense** — picking a few items at random from a collection (e.g. SGD's random rows of A); unrelated to measuring a continuous signal at evenly spaced points (§7.1, §32). See [Sampling (statistics)](https://en.wikipedia.org/wiki/Sampling_(statistics)).
- **Selection matrix** — a matrix with one 1 per row that keeps some entries of a vector and drops the rest; subsampling, a Bayer mosaic and SGD's row choice are all one (§7, §32).
- **Spectral copy / replica** — the whole spectrum curve redrawn around a multiple of the sampling rate; copy *m* is the original slid by *m·f_s* (§7.2–§7.3). Same concept, different names: spectral copy = replica = spectral image (signal-processing term, unrelated to photographs) = alias (once copies overlap, §8). Analogy: a 12-hour clock face repeating every 12 hours.
- **Frequency axis vs. sampling rate** — a spectrum plot's horizontal axis is the frequency of the *signal's own waves* (image frequency in cycles/pixel, spatial in cycles/mm, or temporal in Hz); the sampling rate f_s is not an axis but the *distance* between copies, and f_s/2 the edge of the central band (§7.3).
- **Fixed ruler vs. per-current-pixel ruler** — two ways to label the frequency axis when resampling: cycles/mm or per *original* pixel (spectrum unchanged by resampling; copy spacing and Nyquist edge move) versus cycles per *current* pixel (Nyquist always 0.5; spectrum looks stretched by D after downsampling, squeezed by D after zero-stuffing). Same picture, converted by a factor D (§7.3, §19).
- **[Nyquist–Shannon sampling theorem](https://en.wikipedia.org/wiki/Nyquist%E2%80%93Shannon_sampling_theorem)** — sampling at f_s ≥ 2 f_max keeps the spectral copies apart, so a band-limited signal can be recovered exactly (§8.1). Same concept, different names: Nyquist–Shannon sampling theorem = Shannon–Nyquist theorem = the sampling theorem.
- **[Nyquist rate](https://en.wikipedia.org/wiki/Nyquist_rate)** — the minimum sampling rate needed to avoid aliasing for a given highest frequency present: 2 f_max. It belongs to the signal, not the sampler (§8.1).
- **[Nyquist frequency](https://en.wikipedia.org/wiki/Nyquist_frequency)** — f_s/2, the highest frequency a given sampling rate can represent; it belongs to the sampler (§8.1). Same concept, different names: Nyquist frequency = folding frequency = Nyquist limit = half the sampling rate. Not the same as the Nyquist rate.
- **Fold line** — the Nyquist frequency seen as a mirror: a frequency Δ above f_s/2 shows up Δ below it (for frequencies up to f_s); aliasing happens if and only if the signal has energy above the fold line (§8.1).
- **[Band-limited](https://en.wikipedia.org/wiki/Bandlimiting)** — containing no frequencies above some f_max (§8.1).
- **[Aliasing](https://en.wikipedia.org/wiki/Aliasing)** — distortion from sampling below a signal's true frequency content (e.g. moiré): a frequency above f_s/2 shows up at |f − f_s·round(f/f_s)|; it cannot be undone after sampling (§8.2–§8.4). Its guises, all the same folding: moiré, jaggies, false color, the wagon-wheel effect (temporal aliasing) and LiDAR range aliasing (§8.4).
- **[Anti-aliasing](https://en.wikipedia.org/wiki/Anti-aliasing_filter)** — low-pass filtering before sampling so nothing above the new Nyquist frequency remains (§8.4, §19). Same concept, different names: anti-aliasing filter = AA filter = prefilter = a low-pass filter with cutoff at the Nyquist frequency; in a camera, the optical low-pass filter (OLPF), also called "AA filter" or "blur filter". In computer graphics, anti-aliasing averages several samples per pixel (a box prefilter) (§8.4).
- **[Jaggies](https://en.wikipedia.org/wiki/Jaggies)** — staircase-shaped slanted edges: aliasing on a pixel grid (§8.4, §19).
- **[False color](https://en.wikipedia.org/wiki/Demosaicing)** — colored fringes on fine gray detail: aliasing of a Bayer mosaic's sparser color samples (§8.4, §21).
- **[Fourier series](https://en.wikipedia.org/wiki/Fourier_series)** — the discrete set of coefficients of a periodic signal; repeating in one domain ⇔ sampled in the other (§9).
- **[DFT](https://en.wikipedia.org/wiki/Discrete_Fourier_transform) / [FFT](https://en.wikipedia.org/wiki/Fast_Fourier_transform)** — converts an image from pixel-brightness representation to spatial-frequency representation; FFT is the efficient algorithm for computing it. The underlying idea (image as sum of 2D waves) was introduced early, in Week 1 §19, for the hybrid-images homework. Exact formula: x̂[k] = Σ x[n] e^{−j2πkn/N}, an orthogonal change of basis x̂ = F x with F⁻¹ = F^H/N, treating the N samples as one period of a repeating signal (§10). The FFT computes it in about N log₂ N operations instead of N² by recursively splitting even and odd samples (§11). The FFT is not a different transform: "the FFT of an image" and "the DFT of an image" are the same numbers (`np.fft.fft2` is the 2D DFT computed by FFT); the continuous Fourier transform (§3) is a different, related object (§11).
- **DFT matrix** — the N×N matrix with entries e^{−j2πkn/N}; its rows are orthogonal sampled waves (§10.2).
- **Circular convolution / zero-padding** — DFT-based convolution wraps around the ends; pad to at least N + K − 1 samples for ordinary convolution (§10.3).
- **[Butterfly](https://en.wikipedia.org/wiki/Butterfly_diagram) / [twiddle factor](https://en.wikipedia.org/wiki/Twiddle_factor)** — the FFT's combine step x̂[k] = E[k] ± e^{−j2πk/N}O[k], and the complex factor in it (§11).

**The lens and the sensor as filters**
- **[PSF](https://en.wikipedia.org/wiki/Point_spread_function) (point spread function)** — how a single point of light gets smeared by an imaging system; introduced and defined in full in Week 4 §18.1 (coded-aperture imaging). This week: the lens's blur kernel, caused by aberrations and diffraction, so that blurred = sharp ∗ PSF when the blur is shift-invariant (§12). Every shift-invariant PSF is a convolution kernel, but only kernels that are never negative and sum to 1 can be PSFs; it is measured by photographing a point source (§12.3).
- **[Point source](https://en.wikipedia.org/wiki/Point_source)** — something effectively a single point of light (a distant star, a back-lit pinhole, a far-away LED): the optical impulse, whose photo is the PSF (§6.1, §12.3).
- **Blurring** — convolving with a kernel that is non-negative, sums to 1 and is wider than one pixel; exactly the kernels the non-negative-kernel rule proves low-pass (§12.3).
- **[Optical aberration](https://en.wikipedia.org/wiki/Optical_aberration)** — a real lens's departure from ideal focusing: [chromatic](https://en.wikipedia.org/wiki/Chromatic_aberration) (colors focus differently), [spherical](https://en.wikipedia.org/wiki/Spherical_aberration) (edge rays focus closer); [coma](https://en.wikipedia.org/wiki/Coma_(optics)) and [distortion](https://en.wikipedia.org/wiki/Distortion_(optics)) vary across the frame and so are not shift-invariant (§12.2).
- **[Diffraction](https://en.wikipedia.org/wiki/Diffraction)** — bending/spreading of light through small openings — limits how sharply any lens or pinhole can focus. Computed with Fourier transforms: aperture → coherent PSF → incoherent PSF → OTF (§13).
- **[Fraunhofer diffraction](https://en.wikipedia.org/wiki/Fraunhofer_diffraction)** — the far-field regime in which the light pattern behind an opening is the opening's Fourier transform (§13.1).
- **[Coherent](https://en.wikipedia.org/wiki/Coherence_(physics)) vs. incoherent light** — coherent (laser) waves add by amplitude and can interfere; incoherent (ordinary) light adds by intensity (§13.1).
- **Coherent / incoherent PSF** — the wave amplitude on the sensor (the aperture's Fourier transform) and the intensity a sensor records (its squared magnitude) (§13.2).
- **[Autocorrelation](https://en.wikipedia.org/wiki/Autocorrelation)** — the overlap of a function with a shifted copy of itself, as a function of shift; the aperture's autocorrelation is the OTF (§13.2).
- **[Airy disk / Airy pattern](https://en.wikipedia.org/wiki/Airy_disk)** — the diffraction PSF of a circular aperture: a bright disc of radius 1.22 λN plus faint rings (§13.4–§13.5).
- **Jinc / [Bessel function](https://en.wikipedia.org/wiki/Bessel_function) of the first kind** — the 2D (circular) counterpart of the sinc, J₁(2πρ)/ρ, the Fourier transform of a disc (§13.4, §16.2). *(No standalone Wikipedia article for "jinc".)*
- **Anisotropic blur** — blur that depends on direction, as from a square aperture; circular apertures avoid it (§13.4).
- **Beam divergence (LiDAR)** — a laser beam's angular spread, at best θ ≈ 1.22 λ/D for exit aperture D; sets the spot size and angular resolution (§13.6). See [Beam divergence](https://en.wikipedia.org/wiki/Beam_divergence).
- **[Speckle](https://en.wikipedia.org/wiki/Speckle_(interference))** — the grainy interference pattern coherent light makes on reflection from a rough surface (§13.6).
- **[OTF](https://en.wikipedia.org/wiki/Optical_transfer_function) / [MTF](https://en.wikipedia.org/wiki/Optical_transfer_function)** — the PSF's Fourier transform (complex: contrast and shift per frequency) and its magnitude (contrast only); a lens's OTF falls to zero at the cutoff 1/(λN) (§13–§14). For any non-negative PSF summing to 1, OTF(0) = 1 and |OTF| ≤ 1 everywhere (triangle inequality), so every PSF is low-pass (§14). Same concept, different names: OTF (optical transfer function) = the blur's frequency response = transfer function = Fourier transform of the PSF (written C here, K in Part 6, H or G in PS4); MTF = |OTF| = magnitude response.
- **[Optical low-pass filter](https://en.wikipedia.org/wiki/Anti-aliasing_filter)** — any optical element (lens blur, or a dedicated plate) that removes high spatial frequencies before the sensor (§14, §21).
- **[Irradiance](https://en.wikipedia.org/wiki/Irradiance)** — light power per unit area arriving at the sensor, W/m² (§15.1).
- **Pixel pitch / [fill factor](https://en.wikipedia.org/wiki/Fill_factor_(image_sensor))** — center-to-center pixel spacing p (= the sensor's sampling interval); fraction of each pixel's area that collects light (§15.1).
- **Detector footprint MTF** — |sin(πξw)/(πξw)|, the loss of contrast from each pixel averaging over its width w; zero at ξ = 1/w (§15.2).
- **Sensor Nyquist frequency** — 1/(2p) cycles/mm for pixel pitch p; finer detail aliases (§15.3).

**Filtering**
- **[Low-pass](https://en.wikipedia.org/wiki/Low-pass_filter) / [high-pass](https://en.wikipedia.org/wiki/High-pass_filter) / [band-pass](https://en.wikipedia.org/wiki/Band-pass_filter) filter** — keep low frequencies (broad shapes; the effect is a blur), high frequencies (edges), or a ring in between (§5.4, §16–§17). A high-pass kernel δ − c_LP sums to 0, so flat regions come out exactly 0; display a high-pass result shifted by 0.5 or rescaled to [0, 1], or it looks almost black (§16.4, §17.1).
- **[Cutoff frequency](https://en.wikipedia.org/wiki/Cutoff_frequency) / [passband](https://en.wikipedia.org/wiki/Passband) / [stopband](https://en.wikipedia.org/wiki/Stopband)** — the frequency where a filter's gain drops from passing to blocking (abrupt for an ideal filter, a gradual roll-off for a practical one); the kept range and the removed range (§5.4).
- **Oriented band-pass filter** — keep two opposite wedges of a ring, i.e. edges of one orientation (§17.3).
- **[Ringing](https://en.wikipedia.org/wiki/Ringing_artifacts) / [Gibbs phenomenon](https://en.wikipedia.org/wiki/Gibbs_phenomenon)** — echo bands beside edges caused by a hard frequency cutoff, whose kernel (sinc/jinc) has negative lobes (§16.2).
- **Kernel truncation / ceil(9σ) kernel size** — cutting a Gaussian kernel off at its border; HW4's starter code uses side length ceil(9σ) (about ±4.5σ, where the Gaussian is ≈ 4 × 10⁻⁵ of its peak) so almost nothing is cut; the primal cost then grows like σ² (§16.4).
- **`psf2otf`** — pads a small kernel to the image size, circularly shifts its center to index (0, 0), and FFTs it, giving the OTF array for Fourier-domain filtering (§16.4).
- **[Wall-clock time](https://en.wikipedia.org/wiki/Elapsed_real_time) / warm-up** — real elapsed time between two clock readings (`time.time()`, `time.perf_counter()`); the first call to a library function is often slower (warm-up), so time several runs and report the median or minimum, with both routes doing the same work (§16.4, §32).
- **[Unsharp masking](https://en.wikipedia.org/wiki/Unsharp_masking)** — sharpen by adding back the detail layer: x ∗ (δ + c_highpass), c_highpass = δ − c_lowpass (§17.2; first in Week 3 §17).
- **[Fourier optics](https://en.wikipedia.org/wiki/Fourier_optics) / 4f system** — a lens produces the Fourier transform of a coherently lit input one focal length away; lens–mask–lens filters images optically (§18).

**Aliasing in practice**
- **[Downsampling](https://en.wikipedia.org/wiki/Downsampling_(signal_processing))** — resampling to fewer samples, e.g. keeping every D-th sample; must be preceded by a low-pass filter below 1/(2D) cycles/pixel (§7.1, §19). Same concept, different names: downsampling and subsampling are often used interchangeably; when it matters, subsampling = discard without filtering, downsampling or decimation = filter first.
- **[Upsampling](https://en.wikipedia.org/wiki/Upsampling)** — inserting new samples between existing ones, followed by a low-pass (interpolation) filter; creates no new detail (§7.1, §19.2). Deepened in §19.3: insert D − 1 zeros between samples (zero-stuffing), then low-pass filter at the *old* Nyquist frequency with gain D; the filter is the interpolation kernel.
- **Zero-stuffing** — step 1 of upsampling: place each measured value in every D-th slot of a finer grid and write 0 between (§19.3). Same concept, different names: zero-stuffing = zero insertion = zero-filling = expansion. It leaves the spectrum unchanged but widens the representable band by D, so D − 1 extra copies sit inside it.
- **Imaging (spectral images)** — the extra spectral copies that zero-stuffing leaves inside the widened band; upsampling's counterpart of aliasing, removed by the interpolation filter (§19.3). Not related to photographs.
- **Interpolation kernel** — the small row of weights h that fills in new samples after zero-stuffing: nearest [1,1], linear [½,1,½] (D = 2), bicubic, Lanczos, ideal sinc; its frequency response decides how much of the extra copies survives (§19.3).
- **[Wagon-wheel effect](https://en.wikipedia.org/wiki/Wagon-wheel_effect)** — temporal aliasing that makes a spinning wheel on film appear slow, stopped or reversed (§20.1).
- **Exposure time as a temporal box filter** — each frame averages the scene over its exposure time τ (= shutter speed = shutter time), a box in time with temporal-frequency gain sinc(fτ), first zero at 1/τ (§20.1).
- **[Motion blur](https://en.wikipedia.org/wiki/Motion_blur) (as temporal anti-aliasing)** — the visible smear from that time-averaging; it attenuates fast motion before frame-rate sampling, a weak temporal counterpart of the optical anti-aliasing filter (§20.1).
- **[Pulse repetition frequency](https://en.wikipedia.org/wiki/Pulse_repetition_frequency) / range ambiguity** — a pulsed LiDAR's pulse rate; echoes from beyond c/(2·PRF) are timed from the wrong pulse and reported too close (§20.2a). Same concept, different names: range ambiguity = range aliasing (§8.4).
- **Phase wrapping (CW time-of-flight)** — a continuous-wave ToF sensor's measured phase repeats every 2π, so distances repeat every c/(2 f_mod) (§20.2b).
- **[Birefringence](https://en.wikipedia.org/wiki/Birefringence) / optical anti-aliasing filter** — a crystal that splits a ray in two by polarization; two layers on a sensor split each point into four, blurring just enough to prevent aliasing (§21).
- **[Moiré pattern](https://en.wikipedia.org/wiki/Moir%C3%A9_pattern)** — false large-scale stripes produced when fine repeating detail aliases (§19, §21).

**Deconvolution**
- **Forward model** — a description of how the thing you care about (the scene) produces what you record (the measurement); this week b = k ∗ i + n, or b = A x + noise (§22.1). Same concept, different names: forward model = image formation model = sensing model = measurement model.
- **Forward problem / [inverse problem](https://en.wikipedia.org/wiki/Inverse_problem)** — predict the measurement from the scene and the model (one clear answer) / work backwards from the measurement to the scene; deconvolution, denoising, demosaicking, HDR merging and LiDAR ranging are all inverse problems (§22.1).
- **[Deconvolution](https://en.wikipedia.org/wiki/Deconvolution) (non-blind / blind)** — recovering the sharp image from a blurred one when the kernel is known / unknown (§22.1–§22.2). Same concept, different names: deconvolution = deblurring = image restoration (when the degradation is blur) = inverse filtering (only the plain divide-by-the-OTF version).
- **[Inverse filter](https://en.wikipedia.org/wiki/Inverse_filter)** — divide the blurred spectrum by the OTF: i_est = F⁻¹(F(b)/F(k)) (PS4: H′ = 1/H); fails because it amplifies noise as N/K where the OTF is small (§22.2–§22.3).
- **Noise model b = k ∗ i + n** — blurred measurement = kernel ∗ sharp image + zero-mean noise independent of the image (§22.3). Even with no added noise, [round-off error](https://en.wikipedia.org/wiki/Round-off_error) (≈ 10⁻¹⁶ relative in 64-bit floats, up to half a gray level in 8-bit images) acts as a tiny noise term that the inverse filter amplifies (§22.3).
- **[Full-waveform LiDAR](https://en.wikipedia.org/wiki/Lidar) return model** — r(t) = p ∗ h(t) + n(t): the transmitted pulse p (the PSF in time) stamped at each surface's round-trip delay, h(t) = Σ a_s δ(t − 2d_s/c), plus noise; separating surfaces is 1D deconvolution (§22.4).
- **Range resolution (LiDAR)** — about c·τ_p/2 for pulse width τ_p ([FWHM](https://en.wikipedia.org/wiki/Full_width_at_half_maximum), full width at half maximum); surfaces closer than this merge into one lump (0.6 m for a 4 ns pulse) (§22.4).
- **Signal-to-noise ratio per frequency, SNR(ω)** — signal variance ÷ noise variance at one frequency; PS4's practical estimate is mean pixel value ÷ noise σ (§23).
- **[Wiener filter](https://en.wikipedia.org/wiki/Wiener_filter)** — a statistically optimal deconvolution method that accounts for noise: K*/(|K|² + 1/SNR), the inverse filter times a damping factor D = |K|²/(|K|² + 1/SNR) that falls to 0 where noise dominates. It minimizes the expected squared error and equals Tikhonov-regularized least squares with λ = 1/SNR (§23–§24, §30). Same concept, different names: Wiener filter = Wiener deconvolution (when undoing blur) = Wiener–Kolmogorov filter; its damping factor = regularizing factor = filter factor (§30); PS4 writes the whole filter H′ or G′ (§23.1).
- **Damping factor (Wiener)** — D = |K|²/(|K|² + 1/SNR), the fraction of the inverse filter's gain 1/K that the Wiener filter keeps at one frequency: 1 = no damping, 0 = frequency zeroed, 1 − D = the part removed (a bigger damping factor means *less* damping). Equals the share of the measured power at that frequency that is real signal, and the fraction of the true signal restored there; D = 1/2 where |K|² = 1/SNR. Not the damping ratio of a vibrating system (§23.1). Same concept, different names: damping factor = regularizing factor = filter factor (§30).
- **[Expected value](https://en.wikipedia.org/wiki/Expected_value) / [independence](https://en.wikipedia.org/wiki/Independence_(probability_theory))** — the long-run average of a random quantity; independent quantities satisfy E[IN] = E[I]E[N] (§24.1).
- **[Well-posed / ill-posed problem](https://en.wikipedia.org/wiki/Well-posed_problem)** — an inverse problem is well-posed if a solution exists, is unique, and is stable (small data changes give small answer changes); ill-posed if any of the three fails. Deconvolution fails uniqueness (OTF zeros) and stability (OTF near-zeros) (§22.1, §33).
- **[Regularization](https://en.wikipedia.org/wiki/Regularization_(mathematics))** — adding an assumption about what a plausible answer looks like, turning an ill-posed problem into a solvable one; this week's examples are the Wiener filter and Tikhonov regularization (§22.1, §23, §30).

**Linear systems**
- **Linear system b = Ax** — measurements = image-formation matrix × unknown image vector; ray optics is linear in intensity (§26).
- **[Rank](https://en.wikipedia.org/wiki/Rank_(linear_algebra)) / [null space](https://en.wikipedia.org/wiki/Kernel_(linear_algebra))** — the number of independent directions a matrix preserves / the inputs it sends to zero, which no measurement can reveal (§27.1).
- **[Condition number](https://en.wikipedia.org/wiki/Condition_number)** — largest ÷ smallest singular value; how much measurement error can be amplified in the solution (§27.2).
- **[Singular value decomposition (SVD)](https://en.wikipedia.org/wiki/Singular_value_decomposition)** — A = UΣVᵀ: rotate, stretch each direction by a singular value, rotate; for a circulant blur the singular values are |OTF| (§27.3).
- **[Overdetermined](https://en.wikipedia.org/wiki/Overdetermined_system) / [underdetermined](https://en.wikipedia.org/wiki/Underdetermined_system) system** — more / fewer measurements than unknowns (tall / wide A) (§28).
- **[Convex](https://en.wikipedia.org/wiki/Convex_function) objective** — bowl-shaped, with a single minimum and no false valleys (§28).
- **[Least squares](https://en.wikipedia.org/wiki/Least_squares) / residual / ℓ₂ norm** — minimize ½‖b − Ax‖₂², the sum of squared prediction misses r = b − Ax; ‖r‖₂ = √(Σ r_i²) (§29.1). Same concept, different names: least squares = ℓ₂ (L2) fitting = minimizing the sum of squared errors; the objective is also the loss, cost or data term; ℓ₂ norm = [Euclidean norm](https://en.wikipedia.org/wiki/Norm_(mathematics)#Euclidean_norm) = a vector's length.
- **Residual (two meanings)** — the residual vector r = b − Ax (each measurement's miss), or, in HW4/PS4 (`residual_l2`, "plot the residual vs. iteration"), the single number ½‖Ax − b‖₂², the objective value (§29.1).
- **[Gradient](https://en.wikipedia.org/wiki/Gradient)** — the vector of partial derivatives, pointing uphill; for least squares it is Aᵀ(Ax − b), from the rules ∇(cᵀx) = c and ∇(xᵀMx) = 2Mx for symmetric M (§29.2).
- **Normal equations** — AᵀAx = Aᵀb: the residual is perpendicular to every column of A, so least squares is an orthogonal [projection](https://en.wikipedia.org/wiki/Projection_(linear_algebra)) onto the column space (§29.2).
- **[Pseudoinverse](https://en.wikipedia.org/wiki/Moore%E2%80%93Penrose_inverse) A⁺** — V Σ⁺ Uᵀ, where Σ⁺ divides by each nonzero singular value and puts 0 where a singular value is 0; x̂ = VΣ⁺Uᵀb is the least-squares solution, the best substitute for A⁻¹ when A is not square or not invertible (§29.2). Same concept, different names: pseudoinverse = Moore–Penrose inverse.
- **`np.linalg.lstsq` / [QR factorization](https://en.wikipedia.org/wiki/QR_decomposition)** — a library least-squares solver that factors A = QR (orthogonal times triangular) and back-substitutes; faster than an SVD and safer than the normal equations; HW4's reference answer (§29.2).
- **[Tikhonov regularization](https://en.wikipedia.org/wiki/Ridge_regression) (ridge)** — x = (AᵀA + λI)⁻¹Aᵀb, adding λ to every eigenvalue so the system is always solvable; λ → 0 gives the least-norm solution (§30).
- **Least-norm solution** — among all exact solutions of an underdetermined system, the shortest one (no null-space component) (§30).
- **Filter factors** — the per-singular-value weights s²/(s² + λ) by which regularization multiplies the plain inverse's 1/s, giving s/(s² + λ) in place of 1/s (§30).
- **[Gradient descent](https://en.wikipedia.org/wiki/Gradient_descent) / step size (learning rate)** — repeat x ← x − α∇f(x); for least squares ∇f = Aᵀ(Ax − b), and α must stay below 2/μ_max (§31.1). Same concept, different names: step size = [learning rate](https://en.wikipedia.org/wiki/Learning_rate) = α (`lr` in code); iteration = optimization step = update; plain GD = full-batch = vanilla gradient descent (when contrasted with SGD).
- **Function handle** — passing "multiply by A" and "multiply by Aᵀ" as functions instead of storing the matrix (§26, §31.1).
- **Adjoint (of a convolution)** — Aᵀ for a blur: convolution with the flipped kernel, or multiplication by F{c}* in the Fourier domain (§31.2). See [Hermitian adjoint](https://en.wikipedia.org/wiki/Hermitian_adjoint).
- **[Outlier](https://en.wikipedia.org/wiki/Outlier)** — one wildly wrong measurement (a dead pixel, a LiDAR echo from a raindrop); least squares is dragged by it because its miss is squared (§31.3).
- **L1 norm ‖v‖₁ = Σ|v_i|** — the sum of absolute values (§31.3). Same concept, different names: ℓ₁ norm = L1 norm = Manhattan norm = [taxicab norm](https://en.wikipedia.org/wiki/Taxicab_geometry).
- **[Least absolute deviations](https://en.wikipedia.org/wiki/Least_absolute_deviations) (LAD)** — minimizing ‖Ax − b‖₁ (also L1 regression); resists outliers (fitting a constant gives a median, not a mean) (§31.3).
- **[Subderivative / subgradient / subdifferential](https://en.wikipedia.org/wiki/Subderivative)** — at a corner, the slope of any line through the corner that stays below the graph (subderivative; subgradient in several variables), and the set of all such slopes (subdifferential); for |t| at t = 0 it is every value in [−1, 1], elsewhere the sign of t (§31.3).
- **[Subgradient descent](https://en.wikipedia.org/wiki/Subgradient_method)** — gradient descent with a subgradient in place of the gradient; with a fixed step size it jitters near the minimum, so the step is often shrunk over iterations (e.g. α_k ∝ 1/√k) (§31.3).
- **[Stochastic gradient descent (SGD)](https://en.wikipedia.org/wiki/Stochastic_gradient_descent) / batch size** — gradient steps computed from a random subset of B rows; the estimate is unbiased (right on average) (§32). "Sampling" rows here is the statistical sense (random choice).
- **Batch / mini-batch** — the rows of A (and entries of b) chosen at random in one SGD iteration; batch size B is how many; B = m is plain GD (§32).
- **[Bias of an estimator](https://en.wikipedia.org/wiki/Bias_of_an_estimator) (unbiased)** — an estimate whose average equals the true value, here E[g(x)] = ∇f(x) (§32).

## Week 6 — Regularized Inverse Problems with ADMM
*(full explanations in [`week6-study-notes.md`](./week6-study-notes.md); this is the lookup-speed version)*

**The problem, restated**
- **[Inverse problem](https://en.wikipedia.org/wiki/Inverse_problem)** — recovering an unknown true signal from indirect or corrupted measurements; in plain words, "working backwards from what the camera recorded to what the scene was." This week every inverse problem takes one form, minimize ½‖b − Ax‖₂² + λΨ(x), with a different A for blur, a single-pixel camera, LiDAR, CT, MRI or hyperspectral imaging (§1, §10, §28).
- **[Ill-posed problem](https://en.wikipedia.org/wiki/Well-posed_problem)** (restated) — a question with no single trustworthy answer: many sharp images explain the same blurry photo, and dividing by small numbers amplifies noise; "there are infinitely many solutions that satisfy the measurements," so a prior is needed to pick one (§1–§2; built in Week 5 §22.1, §33).
- **[Circulant matrix](https://en.wikipedia.org/wiki/Circulant_matrix)** (restated) — the N×N matrix C a wrap-around blur becomes, each row the previous one shifted by one with the overflow coming back at the start; in plain words, "the image is treated as if printed on a loop." It is why C x ↔ F{c}·F{x}, Cᵀx ↔ F{c}*·F{x} and CᵀC x ↔ |F{c}|²·F{x} (§2).
- **[Solver](https://en.wikipedia.org/wiki/Mathematical_optimization)** — a step-by-step search procedure that homes in on the best image; this week's two are Adam and ADMM (§1).

**Probability and the Bayesian view**
- **[Random variable](https://en.wikipedia.org/wiki/Random_variable)** — a quantity whose value is not fixed in advance but follows a pattern over many repetitions, like the noise in one pixel (§3).
- **[Probability density](https://en.wikipedia.org/wiki/Probability_density_function), p(·)** — how likely values near t are, per unit of t; in plain words, "a ranking of which values are likely." It can exceed 1; only the area under it over a range is a probability (§3).
- **[Gaussian (normal) density](https://en.wikipedia.org/wiki/Normal_distribution)** — p(t) = 1/√(2πσ²)·exp(−(t − μ)²/(2σ²)), written t ∼ 𝒩(μ, σ²): a bell curve, "a pile of sand poured from one spot," with peak at the mean μ and width the standard deviation σ (σ² = the [variance](https://en.wikipedia.org/wiki/Variance)); its exponent is a squared distance, which is where squared errors come from (§3). Same concept, different names: Gaussian = normal = bell curve.
- **[Conditional density](https://en.wikipedia.org/wiki/Conditional_probability_distribution), p(b | x)** — "the density of b given x": how likely each measurement is if we assume the true image is x; the bar means "assuming" (§3).
- **[Independence](https://en.wikipedia.org/wiki/Independence_(probability_theory)) → multiply** — quantities that do not influence each other (the noise in two different pixels) have a joint probability equal to the product of their separate ones, like two fair coins both landing heads, ½ × ½ (§3, §4).
- **[Proportional to](https://en.wikipedia.org/wiki/Proportionality_(mathematics)) (∝)** — p ∝ q means p = constant × q; constants never move a maximum or minimum, so they can be dropped (§3).
- **[Likelihood](https://en.wikipedia.org/wiki/Likelihood_function)** — p(b | x) ∝ exp(−‖b − Ax‖₂²/(2σ²)) under Gaussian noise: a score of how well a candidate image explains the measured data; in plain words, "if this were the true scene, how believable is what we measured?" (§4). Same concept, different names: likelihood = image formation model in probabilistic form (slide 27) = data model = noise model.
- **[Bayes' rule](https://en.wikipedia.org/wiki/Bayes%27_theorem)** — p(x | b) = p(b | x)·p(x)/p(b): turns "given the image, how likely is this data?" into "given this data, how likely is each image?"; posterior ∝ likelihood × prior. In plain words, a doctor's diagnosis weighing how well symptoms fit (likelihood) against how common each illness is (prior) (§5). Same concept, different names: Bayes' rule = Bayes' theorem.
- **[Posterior](https://en.wikipedia.org/wiki/Posterior_probability)** — p(x | b), Latin for "coming after": how plausible image x is after seeing the data (§5).
- **[Prior](https://en.wikipedia.org/wiki/Prior_probability)** — p(x), "coming before": how plausible x is as an image before any data; real photos are likely, TV static is not (§5).
- **[Evidence](https://en.wikipedia.org/wiki/Marginal_likelihood)** — p(b), how likely the data was overall, averaged over every possible image; the same for every candidate x, so it is a dropped constant (§5).
- **[MAP estimate](https://en.wikipedia.org/wiki/Maximum_a_posteriori_estimation)** — x_MAP = argmin_x (1/(2σ²))‖b − Ax‖₂² + Ψ(x): the single image with the highest posterior, "the most likely image, after seeing the data," found by taking −log so products become sums (§5). Same concept, different names: MAP = maximum a posteriori = posterior [mode](https://en.wikipedia.org/wiki/Mode_(statistics)) (mode = the peak, the most common value).
- **[argmin](https://en.wikipedia.org/wiki/Arg_max)** — "the value of x that makes the following expression smallest": the location of the minimum, not the minimum value itself (§5).
- **Data fidelity term** — (1/(2σ²))‖b − Ax‖₂² (or ½‖b − Ax‖₂²), the part of the objective that comes from the noise and rewards reproducing the measurements; in plain words, "does the answer match what was measured?" (§4–§5). Same concept, different names: data fidelity term = data term = data-consistency term = loss (Week 5 §29) = −log likelihood.
- **Natural image prior / [regularization](https://en.wikipedia.org/wiki/Regularization_(mathematics))** — assumptions about what real images typically look like, used to make an ill-posed inverse problem solvable. Made precise this week as the regularizer Ψ(x) = −log p(x): a number that is small for plausible images, added to the data term as λΨ(x); in plain words, "a built-in sense of what a real photo should look like" (§5, §7). Same concept, different names: prior ↔ regularizer = regularization term = image prior = penalty, Ψ(x) (some slides write Γ(x)).
- **Regularization weight λ** — the dial between "believe the data" (small λ) and "believe what images usually look like" (large λ); from the Bayesian derivation λ plays the role of σ² times the prior's strength, so more noise → larger λ (§5). A Gaussian prior gives Week 5's Tikhonov regularization, with λ = σ²/τ² (§5).

**Image priors**
- **[Norm](https://en.wikipedia.org/wiki/Norm_(mathematics))** — a rule that turns a list of numbers into one "size" that is never negative, is zero only for the all-zero list, doubles when every entry doubles, and obeys the triangle inequality (§6).
- **ℓ₂ / ℓ₁ / "ℓ₀" norms** — straight-line length √(Σv_i²) (Euclidean); sum of absolute values Σ|v_i| (Manhattan / taxicab, "blocks walked on a grid"); number of nonzero entries (a counting "norm," not a true norm) (§6). Minimizing ℓ₁ gives sparse answers because the diamond-shaped ℓ₁ ball touches a line of solutions at a corner, where a coordinate is exactly zero; minimizing ℓ₂ spreads values out (§6).
- **[Sparse](https://en.wikipedia.org/wiki/Sparse_approximation)** — "thinly scattered": a vector whose entries are mostly exactly zero (small ℓ₀), a few meaningful values among zeros (§6).
- **[Laplace distribution](https://en.wikipedia.org/wiki/Laplace_distribution)** — p(t) ∝ exp(−|t|/β), the prior behind an ℓ₁ penalty: a sharper peak at 0 than a Gaussian and heavier tails; in plain words, "most values are exactly or nearly zero, but a few can be large," the statistics of image gradients (§6).
- **[Heavy tails](https://en.wikipedia.org/wiki/Heavy-tailed_distribution)** — tails are a curve's far-left and far-right ends (the large values); heavy tails fall off slowly, so large values stay reasonably likely rather than practically impossible as under a Gaussian (§6).
- **[Laplacian](https://en.wikipedia.org/wiki/Discrete_Laplace_operator) / [curvature](https://en.wikipedia.org/wiki/Curvature)** — Δ, how much a pixel differs from the average of its neighbors, i.e. how much the brightness surface bends there; the kernel [0 1 0; 1 −4 1; 0 1 0], zero on flat regions and straight ramps. ‖Δx‖₂² is the "smooth everywhere" prior, good for blurry stuff, bad for photos with edges (§7). Same concept, different names: Laplacian = Laplace operator = Δ.
- **Three example priors** — smooth images → ‖Δx‖₂ (slide 38; usually used squared, ‖Δx‖₂²); stars (mostly black) → ‖x‖₁; natural photos (flat regions separated by sharp edges) → TV(x), sparse image gradients (§7).
- **[Finite difference](https://en.wikipedia.org/wiki/Finite_difference) / [image gradient](https://en.wikipedia.org/wiki/Image_gradient)** — "next pixel minus this pixel": (D_x x)[r, s] = x[r, s+1] − x[r, s] horizontally, (D_y x)[r, s] = x[r+1, s] − x[r, s] vertically, like measuring a staircase's slope one step at a time; each is a convolution with a 2-tap kernel, so in the Fourier domain D_x x = F⁻¹{F{d_x}·F{x}} (§8). Same concept, different names: finite difference = discrete derivative = image gradient (both directions stacked) = gradient operator D = `grad_fn` (HW5 Task 1–2) = `opDx` (HW5 Task 3). Not the objective gradient ∇f (§1, §11).
- **[Cross-correlation](https://en.wikipedia.org/wiki/Cross-correlation)** — sliding a "multiply-and-sum template" across an image without flipping it; true convolution flips the kernel first, which is why the lecture's and PS5's d_x kernels look mirrored yet describe the same forward difference (§8).
- **Gradient operator D = [D_x; D_y]** — the two difference images stacked: N pixels in, 2N numbers out; HW5 stores D x as an array of shape [2, M, N], horizontal in slot 0, vertical in slot 1 (§8).
- **[Circular (periodic) boundary](https://en.wikipedia.org/wiki/Periodic_boundary_conditions)** — the FFT's assumption that the image wraps around, so the last column's right-hand neighbor is the first column, "as if the image were printed on a tube"; it creates fake edges where opposite borders differ (§8).
- **Dᵀ, the [adjoint](https://en.wikipedia.org/wiki/Hermitian_adjoint) / [divergence](https://en.wikipedia.org/wiki/Divergence)** — the transpose of the gradient operator, "send each difference back onto the two pixels it came from"; for the 1D forward difference with wrap-around, (Dᵀw)[i] = w[i−1] − w[i], and in the Fourier domain D_xᵀ ↔ F{d_x}* (§8). Same concept, different names: Dᵀ = `opDtx` = adjoint of the gradient = minus the discrete divergence ("how much a field of arrows spreads outward from a point, like water from a spring").
- **DᵀD as a high-pass filter** — DᵀD is minus a Laplacian (1D kernel [−1, 2, −1]); in the Fourier domain |F{d_x}|² = 4 sin²(πk/N), 0 at k = 0 and largest (4) at the Nyquist frequency, so it "measures how much fine detail an image has" (§8).
- **[Total variation (TV)](https://en.wikipedia.org/wiki/Total_variation_denoising)** — the sum over pixels of the image-gradient size, an ℓ₁-type penalty on image gradients; in plain words, a hike's total climb plus descent: one cliff and flat plains is cheap, constant small bumps (noise) are expensive. It charges a sharp step and a soft ramp the same, so edges survive and noise is removed (§7, §9). Same concept, different names: total variation = TV = TV regularizer = TV prior = TV pseudo-norm (= semi-norm).
- **[Isotropic](https://en.wikipedia.org/wiki/Isotropy) TV** — Σ_i √((D_x x)_i² + (D_y x)_i²) = ‖D x‖₂,₁, the true length of each pixel's gradient arrow. "Isotropic" is Greek *iso* = "same" + *tropos* = "direction": behaves the same in every direction, like a round ball; it charges an edge the same whatever its orientation ("better," slide 41) (§9). Same concept, different names: isotropic TV = ℓ₂,₁ version ("ℓ₂ inside, ℓ₁ outside") = group sparsity (each pixel's two differences are kept or zeroed together).
- **[Anisotropic](https://en.wikipedia.org/wiki/Anisotropy) TV** — Σ_i (|(D_x x)_i| + |(D_y x)_i|) = ‖D_x x‖₁ + ‖D_y x‖₁, the gradient measured like a taxi on a grid. "Anisotropic" (*an-* = "not") means "direction matters," like wood that splits along the grain; it charges diagonal edges up to √2 ≈ 1.41× more and so reshapes them into stair-steps ("easier," slide 41, since each term uses one difference) (§9).
- **[Pseudo-norm / semi-norm](https://en.wikipedia.org/wiki/Seminorm)** — "almost a norm": TV is zero for any constant image, not only the zero image, so it says nothing about overall brightness and the data term must pin that down (§9). Same concept, different names: pseudo-norm ("false norm") = semi-norm ("half norm").
- **Staircasing** — TV's side effect of turning smooth slopes (a sky, a curved cheek) into flat terraces, "a ramp rebuilt as a staircase" (§9, §27.4).
- **[Chain rule](https://en.wikipedia.org/wiki/Chain_rule)** — the derivative of a function of a function is the product of the two derivatives (§9, §11).
- **[NaN](https://en.wikipedia.org/wiki/NaN) / the `torch.sqrt` trap** — NaN = "not a number," what floating-point arithmetic returns for ∞ × 0; d/dt √t = 1/(2√t) is infinite at t = 0, so isotropic TV built with `torch.sqrt` gets a NaN gradient in flat regions, which poisons every pixel. Use `torch.abs` / `torch.norm` / `torch.sum`, which return a valid subgradient (0) at an exact zero (§9).

**Solver 1: Adam**
- **Objective** — the single number a solver tries to make as small as possible (§10–§11). Same concept, different names: objective = [loss](https://en.wikipedia.org/wiki/Loss_function) = cost.
- **Objective gradient ∇f** — the vector of partial derivatives of the cost with respect to every unknown pixel value, "the direction in which the cost rises fastest"; what gradient descent and `.backward()` compute. Not the image gradient (§1, §11).
- **[Automatic differentiation](https://en.wikipedia.org/wiki/Automatic_differentiation) / [computational graph](https://en.wikipedia.org/wiki/Automatic_differentiation)** — PyTorch records every operation of the loss computation in a computational graph ("a diagram of which numbers were combined, how, to make which"); `loss.backward()` walks it backwards with the chain rule and stores ∇f in `x.grad`; `optim.zero_grad()` clears it first because `.backward()` adds to what is stored (§11). Same concept, different names: automatic differentiation = autograd = [backpropagation](https://en.wikipedia.org/wiki/Backpropagation) (in neural networks).
- **[PyTorch](https://en.wikipedia.org/wiki/PyTorch)** — a Python library for numerical computing and neural networks that differentiates code automatically (§11).
- **[Adam](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#Adam)** — a gradient method that keeps a running average of recent gradients (smoothing out jumps) and divides each pixel's step by a running estimate of its typical gradient size, so each pixel moves about α per step whatever the problem's scale; "convenient but doesn't always converge well," since it hovers near the minimum (§11). Same concept, different names: Adam = adaptive moment estimation.
- **[Moment](https://en.wikipedia.org/wiki/Moment_(mathematics)) (first / second)** — statistics word for an average of a power of a quantity: the 1st moment is the mean, the 2nd the mean of the square. In Adam, m_k (first moment) = running mean of gradients = momentum; v_k (second moment) = running mean of squared gradients, each pixel's typical gradient size (RMS after the square root) (§11).
- **[Momentum](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#Momentum)** — averaging gradients over steps so the consistent downhill direction builds up and back-and-forth flips cancel, "a ball rolling downhill does not stop at every bump" (§11).
- **[Exponential moving average](https://en.wikipedia.org/wiki/Moving_average#Exponential_moving_average)** — a running average where each older value counts a fixed fraction (β) as much as the next newer one; β₁ = 0.9 remembers about 1/(1 − 0.9) = 10 steps, β₂ = 0.999 about 1000 (§11).
- **Bias correction** — dividing Adam's running averages by 1 − β^k, which scales up the too-small early averages caused by starting m and v at 0 (at k = 1 it recovers g₁ exactly) (§11).
- **[Learning rate](https://en.wikipedia.org/wiki/Learning_rate) α** (restated) — roughly "how far a pixel value may move per step" in Adam; HW5 Task 1 uses 5 × 10⁻² (§11). Same concept, different names: learning rate = step size = α = `lr`.
- **[Hyperparameter](https://en.wikipedia.org/wiki/Hyperparameter_(machine_learning))** — a setting you choose before running (learning rate, λ, number of iterations), as opposed to the unknowns the solver finds (§11).

**Constrained optimization**
- **Splitting / split variable z** — giving the regularizer its own copy of the unknown, minimize f(x) + g(z) subject to Kx − z = 0 (K = D for TV, K = I for a denoiser prior); mathematically equivalent to the original, but lets each term be handled by the method it suits, like a plumber and an electrician each working on their own copy of a plan and meeting to reconcile (§13). Same concept, different names: split variable = slack variable (loosely) = auxiliary variable.
- **[Constraint](https://en.wikipedia.org/wiki/Constraint_(mathematics))** — a condition the answer is required to satisfy; "subject to" = "while obeying the condition that" (§13).
- **[Level curve](https://en.wikipedia.org/wiki/Contour_line)** — a line of equal height of a function, like contour lines on a hiking map (§14). Same concept, different names: level curve = contour = isoline.
- **[Lagrange multiplier](https://en.wikipedia.org/wiki/Lagrange_multiplier)** — a number y attached to a constraint; at a constrained minimum the constraint is [tangent](https://en.wikipedia.org/wiki/Tangent) to a level curve ("touches without crossing"), so ∇f is parallel to the constraint's gradient, ∇f = −y·∇(constraint). In plain words, finding the lowest point of a park while staying on a footpath (§14). Same concept, different names: Lagrange multiplier = dual variable = [shadow price](https://en.wikipedia.org/wiki/Shadow_price), written y on the slides (λ in many textbooks).
- **[Lagrangian](https://en.wikipedia.org/wiki/Lagrange_multiplier)** — L = f + yᵀ(constraint): one function whose zero partial derivatives give both the tangency condition and the constraint itself (§14).
- **[Shadow price](https://en.wikipedia.org/wiki/Shadow_price)** — what a constraint "costs" you: |y| is how much the best objective would improve if the constraint were loosened a little (§14).
- **[Primal / dual](https://en.wikipedia.org/wiki/Duality_(optimization)) variables** — "primal" = the original unknowns (x, z); "dual" = the partners attached to the constraints (y, or u) (§14).
- **[Method of multipliers](https://en.wikipedia.org/wiki/Augmented_Lagrangian_method)** — repeat: find the best x for the current price y, then raise the price in proportion to how much the constraint was broken, like a city raising a parking fine until nobody parks illegally (§15).
- **[Augmented Lagrangian](https://en.wikipedia.org/wiki/Augmented_Lagrangian_method)** — L_ρ = f(x) + g(z) + yᵀ(Kx − z) + (ρ/2)‖Kx − z‖₂²: the Lagrangian plus a quadratic [penalty](https://en.wikipedia.org/wiki/Penalty_method) ("augmented" = "with something added"); the penalty makes each sub-problem a well-behaved bowl, the multiplier makes the answer exact without ρ → ∞ (§15).
- **Penalty parameter ρ** — how hard a constraint violation is punished in the augmented Lagrangian; you choose it (§15). A penalty alone (no multiplier) satisfies the constraint only as ρ → ∞ (§15, §22).
- **[Completing the square](https://en.wikipedia.org/wiki/Completing_the_square)** — the school trick a r + (ρ/2)r² = (ρ/2)(r + a/ρ)² − a²/(2ρ), which merges the linear and quadratic constraint terms into one square (§16).
- **Scaled dual variable u** — u = y/ρ, the price measured in the same units as Kx; gives the scaled form L_ρ = f(x) + g(z) + (ρ/2)‖Kx − z + u‖₂² − (ρ/2)‖u‖₂²; in ADMM it is the running total of past disagreements Kx − z, like a thermostat adding up how long the room has been too cold (§16–§17). Same concept, different names: u = scaled dual variable = scaled Lagrange multiplier = "running residual sum."

**Solver 2: ADMM and its steps**
- **[ADMM](https://en.wikipedia.org/wiki/Alternating_direction_method_of_multipliers)** — an optimization algorithm splitting a hard joint problem into easier alternating sub-steps. Precisely: minimize the scaled augmented Lagrangian over x with z frozen (data step), over z with x frozen (prior step), then update the price u ← u + Kx − z; in plain words, "apply the data prox, apply the prior prox, update the price," repeated (HW5: 75 iterations) (§17). Same concept, different names: ADMM = alternating direction method of multipliers; x-update = data step; z-update = prior step = regularization step; u-update = dual update = dual ascent step.
- **[Proximal operator](https://en.wikipedia.org/wiki/Proximal_operator)** — prox_{λf}(v) = argmin_x f(x) + (1/(2λ))‖x − v‖₂²: the point near v that does best on f, "a dog on a leash," where the dog wants f's lowest point and the leash ties it to v; both ADMM steps are proxes (§18). Same concept, different names: proximal operator = prox = proximal mapping = "proximal point of v with respect to f"; x-update = prox_{‖·‖₂,ρ}; z-update = prox_{‖·‖₁,ρ} (TV) or prox_{𝒟,ρ} (denoiser).
- **Soft thresholding** — S_κ(v) = sign(v)·max(|v| − κ, 0) = max(1 − κ/|v|, 0)·v with κ = λ/ρ, the prox of the ℓ₁ norm: "shrink toward zero by κ, and stop at zero," like a tax with a flat deduction that wipes out anything smaller than κ; it is where TV's exact zeros (flat regions) come from (§19). Same concept, different names: soft thresholding = shrinkage = soft shrinkage = prox of the ℓ₁ norm, written 𝒮_κ. *(No standalone Wikipedia article; covered under proximal operators.)*
- **Hard thresholding** — keep values above the threshold unchanged and set the rest to zero; unlike soft thresholding, it does not pull the survivors in by κ (§19).
- **Block soft thresholding** — z_i = max(1 − κ/‖v_i‖₂, 0)·v_i: for isotropic TV, shrink each pixel's gradient arrow's length by κ, keep its direction, and zero it if it was shorter than κ (§19). Same concept, different names: block soft thresholding = group shrinkage = prox of the ℓ₂,₁ norm.
- **[Closed-form](https://en.wikipedia.org/wiki/Closed-form_expression) solution** — an answer written down directly, with no iterating, e.g. the deconvolution x-update (CᵀC + ρDᵀD)⁻¹(Cᵀb + ρDᵀv), computed by Fourier-domain division (§20). Same concept, different names: closed-form = analytic solution.
- **Numerator / denominator (of the x-update)** — the denominator |F{c}|² + ρ(|F{d_x}|² + |F{d_y}|²) never changes during ADMM, so it is computed once; the numerator contains v = z − u and is recomputed every iteration ("nominator" in the HW text means numerator) (§20).

**Learned priors**
- **[Denoiser](https://en.wikipedia.org/wiki/Noise_reduction) 𝒟** — any method that removes noise from an image; the ADMM z-update argmin λΨ(z) + (ρ/2)‖v − z‖² is exactly MAP denoising of v with noise variance σ² = λ/ρ, so a denoiser can stand in for it (§21). Not the matrix D.
- **Plug-and-play (PnP) prior** — using an off-the-shelf denoiser as ADMM's prior step, making the prior a replaceable part; there is no explicit Ψ and convex convergence guarantees no longer strictly apply, but it works well in practice (§21). Same concept, different names: plug-and-play prior = denoiser prior = learned prior (when the denoiser is a trained network) = "ADMM with denoiser."
- **[CNN](https://en.wikipedia.org/wiki/Convolutional_neural_network)** — a convolutional neural network: a stack of layers, each convolving the image with many small learned kernels and then applying a nonlinearity (§21).
- **[Nonlinearity](https://en.wikipedia.org/wiki/Activation_function)** — a fixed bend applied between network layers, such as "replace negative values by 0"; without it a stack of convolutions would collapse into a single convolution (§21). Same concept, different names: nonlinearity = activation function.
- **DnCNN** — "denoising convolutional neural network": HW5's 17-layer, 64-channel CNN trained on noise of standard deviation 25/255 ≈ 0.098, so λ/ρ is chosen to match that level (§21).
- **Residual learning** — training a network to predict the *noise* and subtract it, because recognizing "what looks like noise" is easier than drawing a whole clean image (§21).
- **[Batch normalization](https://en.wikipedia.org/wiki/Batch_normalization)** — a layer that rescales values using averages over the current training batch; `model.eval()` freezes it to its trained settings (§21).
- **[Non-local means](https://en.wikipedia.org/wiki/Non-local_means)** (restated) — a classical denoiser that averages pixels whose surrounding patches look alike; another possible plug-in for 𝒟 (§21; built in Week 3 §16.3).
- **Half-quadratic splitting (HQS)** — ADMM without the price u: alternate x and z steps on f(x) + g(z) + (ρ/2)‖Dx − z‖₂²; simpler, but exact only as ρ → ∞, so "very sensitive to the penalty parameter" and usually run with a growing ρ (§22). Same concept, different names: HQS = half-quadratic splitting = quadratic penalty method with alternating minimization.
- **Unrolled optimization** — running ADMM or HQS for a fixed K iterations, drawing the chain as layers of a network, and training per-iteration parameters (λ^(k), ρ^(k), even a separate denoiser) on example images; the idea behind the HW5 bonus (§22). Same concept, different names: unrolled optimization = algorithm unrolling = deep unfolding = "unrolled feedforward network."
- **[Feedforward network](https://en.wikipedia.org/wiki/Feedforward_neural_network)** — a pipeline of layers where data flows one way, each layer feeding the next, with no loops back (§22).
- **[Skip connection](https://en.wikipedia.org/wiki/Residual_neural_network)** — a shortcut that hands a layer's output directly to later layers, not only the next one ("DenseNet-like" names a well-known network built that way) (§22).
- **Perceptual / [adversarial](https://en.wikipedia.org/wiki/Generative_adversarial_network) loss** — perceptual: compare images by the features a trained network sees in them, closer to human judgment than pixel-by-pixel MSE; adversarial: a second network tries to tell results from real photos and the first is trained to fool it (§22).

**Compressive imaging and the single-pixel camera**
- **[Single-pixel imaging](https://en.wikipedia.org/wiki/Single-pixel_imaging)** — reconstructing a full image from many single-value measurements plus known coded illumination patterns. Precisely: a lens images the scene onto a DMD, a pattern of mirrors sends part of the light to one photodiode, and each reading is b_m = a_mᵀx; repeat M times, b = Ax + η. Useful where large sensor arrays are expensive or impossible (infrared, terahertz) (§23). The "single pixel" is the one detector; the reconstructed image still has N image pixels, one per DMD pattern cell.
- **Sensor pixel vs. image pixel** — a *sensor pixel* (= detector) is a physical light-sensing cell; an *image pixel* is one value of the output picture. A normal camera has one sensor pixel per image pixel, so "pixel" covers both; a single-pixel camera has one sensor pixel (the photodiode) but reconstructs N image pixels, one per DMD **pattern cell** (one mirror or a small block of mirrors) (§23). Same concept, different names: image pixel = scene pixel = pattern cell.
- **[Digital micromirror device (DMD)](https://en.wikipedia.org/wiki/Digital_micromirror_device)** — a chip covered in hundreds of thousands of microscopic mirrors, each tilting "on" (toward the detector) or "off"; the on/off layout is the pattern (mask); the same chip is used in many video projectors (§23).
- **[Photodiode](https://en.wikipedia.org/wiki/Photodiode)** — a single light sensor (one sensor pixel on its own) that reports one number, the total light reaching it; in the single-pixel camera it is the only detector, the "single pixel" of the name (§23). Same concept, different names: detector = photodiode = bucket detector.
- **Measurement matrix A** — one pattern per row; for HW5 Task 3, M = 1024 random gray-level masks on a 64×64 (N = 4096) image; `Afun` = Ax (masks times image, summed), `Atfun` = Aᵀb (masks weighted by readings, summed) (§23). Same concept, different names: measurement matrix = sensing matrix = A. Watch the names: the starter code's `N` is the lecture's M.
- **[Compressive imaging](https://en.wikipedia.org/wiki/Compressed_sensing)** — measuring fewer numbers than image pixels (M < N), so the camera "compresses while measuring" instead of measuring everything and compressing afterwards as JPEG does; the compression factor is N/M (HW5: 4) (§23). Same concept, different names: compressive imaging = compressed sensing setting (M < N).
- **[Under-determined](https://en.wikipedia.org/wiki/Underdetermined_system)** (restated) — more unknowns than equations, so infinitely many exact solutions exist (§23–§24; Week 5 §28). Same concept, different names: under-determined = compressive (M < N).
- **[Null space](https://en.wikipedia.org/wiki/Kernel_(linear_algebra))** (restated) — the changes to the image that leave every reading unchanged; any solution plus a null-space vector is another solution (§24; Week 5 §27.1).
- **Least-norm solution** — x̃_ln = Aᵀ(AAᵀ)⁻¹b, the exact solution with the smallest ℓ₂ norm, derived with a Lagrange multiplier; it is a weighted sum of the patterns, contains no null-space part, and with random patterns looks like speckle ("not great," slide 112); Tikhonov in the limit λ → 0 (§24). Same concept, different names: least-norm = minimum-norm solution = "LN" = the pseudoinverse solution A⁺b for a wide A.
- **[Conjugate gradient (CG) method](https://en.wikipedia.org/wiki/Conjugate_gradient_method)** — solves Ãw = b̃ for symmetric positive definite Ã using one matrix-vector product per step, by choosing conjugate directions that "never undo a previous step"; exact in at most N steps (§25). Used to compute least norm ((AAᵀ)w = b, then x = Aᵀw) and the single-pixel ADMM x-update (§24, §26). Same concept, different names: CG = conjugate gradient method.
- **Conjugate (Ã-orthogonal) directions** — directions that would be perpendicular if space were stretched so the elliptical bowl became round; minimizing along one never spoils the minimization along the others (§25).
- **[Symmetric](https://en.wikipedia.org/wiki/Symmetric_matrix) [positive definite (SPD)](https://en.wikipedia.org/wiki/Definite_matrix)** — Ã = Ãᵀ (mirror-image across the diagonal) and wᵀÃw > 0 for every nonzero w; in plain words, "a bowl that curves up in every direction," so it has exactly one lowest point. AAᵀ (independent patterns), AᵀA + ρDᵀD and AᵀA + ρI all qualify; semi-definite (≥ 0) also works if a solution exists (§25–§26). Same concept, different names: symmetric positive definite = SPD.
- **[Line search](https://en.wikipedia.org/wiki/Line_search) / steepest descent** — steepest descent is gradient descent with the best step length chosen each time ("go downhill until the ground starts rising"), an exact line search; on a stretched bowl it still zig-zags, which CG avoids (§25).
- **Residual r_k (in CG)** — b̃ − Ãw_k, how far the current guess is from solving the system; also minus the bowl's objective gradient (§25).
- **`LinearOperator` / matvec / matrix-free** — SciPy's wrapper that presents "a function that applies the matrix" (matvec = matrix-vector product) as a matrix to `scipy.sparse.linalg.cg`, which never stores the matrix; reshape to 64×64 before image functions and flatten after; `cg` returns (solution, info flag); its tolerance argument `tol` was renamed `rtol` in recent SciPy (§25). Same concept, different names: matrix-free = function handle (Week 5 §26) = `LinearOperator`.
- **[Linearly independent](https://en.wikipedia.org/wiki/Linear_independence)** — no pattern can be built as a weighted sum of the others; makes AAᵀ positive definite (§25).
- **Warm start** — starting CG from the previous ADMM iteration's x (SciPy's `x0`) instead of zero, usually reaching the tolerance in fewer iterations; optional (§26).

**LiDAR**
- **[LiDAR](https://en.wikipedia.org/wiki/Lidar)** (restated) — light detection and ranging: measures distance by timing laser light's round trip, d = ct/2 (§27; Week 4, Week 5 §20.2).
- **[Single-photon avalanche diode (SPAD)](https://en.wikipedia.org/wiki/Single-photon_avalanche_diode)** — a detector fast enough to time light to within a nanosecond that "clicks" on individual photons; expensive to build in large arrays, especially at infrared wavelengths like 1550 nm (§27.1).
- **Scanning vs. flash vs. compressive LiDAR** — scanning: steer one beam point by point with one fast detector; flash: light the whole scene and use a full array of fast detectors; compressive (single-pixel): light the whole scene, apply DMD patterns, time the total return with one fast detector (§27.1). Same concept, different names: single-pixel LiDAR = compressive LiDAR = compressive depth imaging.
- **Time bin / [histogram](https://en.wikipedia.org/wiki/Histogram)** — the detector records counts of returned light in each short time slot (bin) after the pulse; a bin of width Δt is a depth slice Δd = cΔt/2 (0.15 m for 1 ns) (§27.2). Same concept, different names: time bin = histogram bin = range bin.
- **Compressive LiDAR forward model B = AX** — each time bin is an ordinary single-pixel problem b_t = Ax_t sharing the same A; X's column t is the image of "what is at depth bin t," and each such slice is sparse (an ℓ₁ prior suits it) (§27.2).
- **[Multiplex advantage](https://en.wikipedia.org/wiki/Fellgett%27s_advantage)** — each pattern sends roughly half the scene's light to the detector instead of one scene point's worth (as in scanning), improving SNR when the detector's own electronic noise dominates (§27.2). Same concept, different names: multiplex advantage = Fellgett advantage (the spectroscopy name).
- **[Poisson distribution](https://en.wikipedia.org/wiki/Poisson_distribution)** (restated) — the probability law for counting independent random events, "raindrops landing on a tile in a minute"; photon counts follow it (shot noise, Week 2 §18), with standard deviation √mean, so a Gaussian noise model is wrong at low counts and the data term becomes Σ[(Ax)_i − b_i log(Ax)_i] (§27.3).
- **Flying pixels** — invented depths that belong to no surface, points floating in mid-air between a foreground object and the background, produced at depth edges when foreground and background are mixed, either by the sensor itself (one sensor pixel's or laser spot's light coming from both) or by ordinary averaging; TV smoothing does not add them (§27.4). The "pixel" in the name is a pixel of the output depth map (an image pixel). Same concept, different names: flying pixels = mixed pixels = edge artifacts in depth maps.
- **Contrast loss** — TV's small bias of moving each plateau toward its neighbor by λ ÷ (plateau length), because it charges for a jump's height (§27.4).
- **Total generalized variation (TGV)** — a higher-order prior that penalizes *changes* in the gradient rather than the gradient itself, so a slanted plane costs nothing; fits depth maps of slanted surfaces better than plain TV (§9, §27.4).

**Compressive imaging elsewhere**
- **[Computed tomography (CT)](https://en.wikipedia.org/wiki/CT_scan)** — an x-ray source and sensor rotate around the patient, each reading the total absorption along one line; a full set of readings at one angle is a **projection**; compressive CT uses fewer angles for less dose (§28). Same concept, different names: CT = computed tomography = CAT scan.
- **[Fourier slice theorem](https://en.wikipedia.org/wiki/Projection-slice_theorem)** — the 1D Fourier transform of the projection at angle θ equals the 2D Fourier transform of the image along a line through the origin at that angle, so each angle fills in one "slice" of the spectrum (§28). Same concept, different names: Fourier slice theorem = projection-slice theorem = central slice theorem.
- **[MRI](https://en.wikipedia.org/wiki/Magnetic_resonance_imaging) / [k-space](https://en.wikipedia.org/wiki/K-space_(magnetic_resonance_imaging))** — magnetic resonance imaging measures the image's Fourier coefficients directly; k-space is radiologists' name for that frequency domain; compressive MRI measures fewer coefficients for shorter scans, A = "Fourier transform, then keep the measured frequencies" (§28).
- **[Hyperspectral imaging](https://en.wikipedia.org/wiki/Hyperspectral_imaging) / datacube** — recording many narrow wavelength bands per pixel (dozens to hundreds, vs. RGB's three), a 3D (x, y, λ) datacube with λ meaning wavelength (§28). Same concept, different names: datacube = spectral cube; hyperspectral (many narrow bands) vs. [multispectral](https://en.wikipedia.org/wiki/Multispectral_imaging) (a handful of bands).
- **CASSI / [coded aperture](https://en.wikipedia.org/wiki/Coded_aperture) / disperser** — the coded aperture snapshot spectral imager captures the whole datacube in one 2D photo: a fixed random mask (coded aperture) patterns the light, a disperser ([prism](https://en.wikipedia.org/wiki/Dispersive_prism) or grating, which bends each wavelength by a different amount) shifts each wavelength's copy sideways, and the sensor sums them; A = "mask, shift by wavelength, sum" (§28).
- **[Hallucination](https://en.wikipedia.org/wiki/Hallucination_(artificial_intelligence))** — a prior producing plausible-looking detail that was never measured (e.g. a learned prior smoothing away a small tumor or inventing a structure); why medical practitioners are "often hesitant about priors" (§28).
